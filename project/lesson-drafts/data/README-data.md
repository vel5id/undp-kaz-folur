# Учебные данные уроков П11/А4 (уровень A, воспроизводимые)

> Создано 2026-07-08. Прототип пересборки Zenodo-пакета (план, этап 0.3).

## Файлы

### `lesson-bathymetry-tracks.csv` — 519 192 промера, 21 МБ

| Колонка | Тип | Описание |
|---|---|---|
| `point_id` | int | сквозной номер |
| `patch_id` | int | участок съёмки (1–6, по убыванию числа точек; 1 = главный, 469 110 т.) |
| `track_id` | int | ход (непрерывный отрезок записи), 1–54 |
| `leg_id` | int | **галсовая линия внутри патча** (по возрастанию поперечной координаты); 0 = развороты и переходы между линиями |
| `seq_in_track` | int | порядок записи внутри хода (хронология судна) |
| `x_m`, `y_m` | float | локальная СК уровня A — **та же, что в опубликованном Zenodo-наборе** (совпадение проверено: 20 000/20 000 выборочных кортежей x,y,depth), округление 0,1 м |
| `depth_m` | float | глубина, ≥ 0; для ГИС использовать `bottom_elevation_m = −depth_m` |

**Что удалено против сырья:** «нулевой ход» (20 758 т. другого объекта в 37 км) и GPS-глюк (5 т.).
**Что сохранено намеренно:** порядок записи, естественные дефекты — ~1% одиночных спайков и 7 210 нулей — это учебный материал для фильтрации (урок 2).
**Чувствительность:** координаты идентичны уже опубликованному уровню A; добавлена только структура ходов/линий (без геопривязки). Реальный берег в набор не входит.

### `lesson-shore-synthetic.csv` — 193 точки

Синтетический контур (граница покрытия главного патча + буфер), `z_m = 0`, колонка `note = synthetic`.
**Это НЕ реальная береговая линия** — учебная замена для урока 2В (берег как граничное условие) по политике фигур (план, п. 0.4).

## Канонический эксперимент (воспроизводит уроки 1 и 2Б)

1. Взять `patch_id == 1`, `depth_m > 0`; эталон: ячейки 10 м, среднее по точкам,
   очищенным вдоль хода (|z − скользящая медиана(11) по `seq_in_track`| ≤ 0,75 м).
2. Прореживание — **по линиям**: `leg_id` отсортированы по положению; каждая k-я линия
   (k = 2/4/6/8/16 → шаг ≈ 20/40/60/80/160 м при фактическом шаге линий 10 м); leg 0 не брать.
3. TIN (`scipy.interpolate.griddata`, linear) → RMSE к эталону; MAD-фильтр: 30 соседей,
   порог 3·1,4826·MAD (мин. 0,3 м). Сглаживание (гаусс σ=1,5 яч.) — только для показа.

Контрольные значения (должны воспроизводиться с точностью ±0,01 м):

| Выборка | Точек | RMSE (TIN) | RMSE + MAD |
|---|---|---|---|
| все точки (шаг 10 м) | 461 900 | 0,24 | **0,11** (−6 976 т.) |
| каждая 2-я линия (~20 м) | 192 749 | 0,26 | 0,13 |
| каждая 4-я (~40 м) | 92 559 | 0,30 | 0,20 |
| каждая 6-я (~60 м) | 57 895 | 0,35 | 0,26 |
| каждая 8-я (~80 м) | 46 962 | 0,38 | 0,33 |
| каждая 16-я (~160 м) | 27 166 | 0,51 | 0,52 — MAD уже не помогает |
