## Правила использования

1. Уровень C не покидает внутренний контур (в git заблокирован явными паттернами `.gitignore`).
2. Любые публикуемые графики — только в локальной/относительной СК.
3. При слиянии съёмок — датум-поправка −0,85 м к старой (проверить на актуальных парах перекрытия).
4. Знак: хранение `depth_m ≥ 0`, показ — `bottom_elevation_m = −depth_m`.
