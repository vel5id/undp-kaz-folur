## Описание

539 955 сырых эхолотных промеров глубин пресноводного водохранилища степной зоны
Казахстана. Полевые экспедиции НАО «Костанайский региональный университет
им. А. Байтұрсынұлы». Уникальный учебный ресурс проекта UNDP-KAZ FOLUR: реальные
исследовательские данные для отработки полного конвейера «сырые промеры → фильтрация
→ интерполяция → карта глубин → расчёт объёма».

## Обезличивание (уровень A политики данных проекта)

- Координаты — локальная система в метрах (`x_m`, `y_m`): начало отсчёта удалено
  безвозвратно, геопривязка и название объекта не раскрываются;
- округление координат 0,1 м; порядок точек перемешан; идентификаторы перегенерированы;
- глубины (`depth_m`, 0–16,1 м) — реальные, без искажений;
- персональные данные отсутствуют.

Генерация: `project/platform/tools/anonymize_bathymetry.py` (детерминированно, seed 20260702).

## Схема данных

| Колонка | Тип | Описание |
|---|---|---|
| point_id | int | порядковый идентификатор (перегенерирован) |
| x_m | float | локальная координата X, м |
| y_m | float | локальная координата Y, м |
| depth_m | float | глубина, м |
