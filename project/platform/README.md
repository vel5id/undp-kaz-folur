# FOLUR Казахстан — учебная платформа

Учебная платформа проекта UNDP-KAZ FOLUR (Food Systems, Land Use and Restoration): устойчивое управление агроландшафтами Северного Казахстана. Исполнитель — НАО «Костанайский региональный университет им. А. Байтұрсынұлы».

**Сайт:** https://folur-kaz-platform.web.app/ (Firebase Hosting; репозиторий приватный)

Деплой: `tools/deploy_firebase.sh` (валидация → strict-сборка → `firebase deploy`). CI на push проверяет контент и сборку.

## Состав

- **21 учебный модуль**: 6 академических (А1–А6) + 15 профессиональных (П1–П15), каждый — лекции, практикум, ИИ-задание, аттестация;
- **Тест-движок** (клиентский): индивидуальные варианты по ID слушателя, pre/post-режим, порог 75%, сертификаты с QR-верификацией;
- **Датасеты**: обезличенный батиметрический учебный набор (уровень A политики данных), производные карты (уровень B);
- **PDF-конспекты** модулей и офлайн-пакет для слабого интернета.

## Локальная сборка

```bash
pip install -r requirements.txt
python tools/validate_content.py   # проверка контента (quiz-JSON, обязательные секции)
mkdocs serve                       # предпросмотр
mkdocs build --strict
```

Служебные инструменты — в `tools/` (генерация навигации, PDF-конспектов, проверка кодов результатов для KPI-реестра, обезличивание данных).

## Лицензия и данные

Учебные материалы открыты. Батиметрические данные распространяются только в обезличенном виде (локальная система координат) в соответствии с политикой данных проекта (см. страницу «Датасеты» на сайте). Публикация полного датасета — на Zenodo с DOI после юридического подтверждения.
