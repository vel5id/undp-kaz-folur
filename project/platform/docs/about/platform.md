# Архитектура платформы

Лёгкое масштабируемое MVP-решение без тяжёлой инфраструктуры: система живёт после завершения проекта без затрат на администрирование ($0/месяц).

| Слой | Решение | Назначение |
|---|---|---|
| Публичный каталог | MkDocs Material + GitHub Pages | входная точка, описания модулей, материалы |
| Хранилище | Git + Git LFS; Zenodo (DOI) для датасетов | PDF, презентации, ноутбуки, батиметрия |
| Практикумы | Google Colab / Kaggle / MyBinder | ноутбуки под аккаунтом слушателя |
| ИИ-слой | Claude Code / OpenCode / GIS Copilot (вендор-независимо) | ИИ-задания в модулях, генерация и верификация геокода |
| Тестирование | собственный тест-движок (Этап 2) | индивидуальные варианты, автопроверка, PDF-сертификаты (порог 75%) |
| Обратная связь | GitHub Discussions | вопросы и замечания слушателей |
| Учёт KPI | Google Sheets + подписанные листы | реестр слушателей (KPI 2.12 ПРООН) |

## Принципы

- **Нулевая инфраструктурная зависимость** — только бесплатные управляемые сервисы;
- **Открытость** — материалы доступны без регистрации; репозиторий передаётся ПРООН и вузам;
- **Доступность** — офлайн-пакеты и PDF-конспекты для слабого интернета; лёгкие ассеты;
- **i18n-готовность** — структура допускает казахскую локализацию без перестройки;
- **Достоверная оценка** — генерация индивидуальных заданий и автопроверка вместо форм, которые «тривиально обходятся».

## Локальная сборка

```bash
pip install -r requirements.txt
mkdocs serve   # предпросмотр на http://127.0.0.1:8000
mkdocs build --strict
```
