# Шаблон модуля (канонический каркас)

Единый каркас всех 21 модулей — по итогам бенчмарка 14 курсов-аналогов (FAO eLearning, NASA ARSET, Coursera, Spatial Thoughts, ITC, Stepik).

## Структура каталога

```
modules/<код>/
  index.md          # программа модуля
  lectures/NN-*.md  # уроки
  practicum/*.md    # guided-проект
  ai-assistant.md   # ИИ-ассистент в работе
  assessment/*.md   # оценивание
```

## Требования к элементам

**`index.md`** — цели по Блуму, таблица уроков с трудозатратами, ожидаемый прикладной продукт, библиография (включая рамки FAO/WOCAT/ЦУР 15.3 — где релевантно).

**Урок (`lectures/`)**:

- название — по производимому результату («Считаем NDVI по полю в GEE», а не «Введение в NDVI»);
- шапка: `> ⏱ **Трудозатраты:** ~N мин чтения + ~M мин практики` (урок 20–50 мин, модуль 2–2,5 ч/нед.);
- один региональный кейс (СКО / Костанайская / Акмолинская область) — обязательно;
- Mermaid-схема ключевой концепции;
- завершающий блок «Закрепление и применение»: «Попробуйте в Colab», «Границы применимости», «Что это даёт вашему хозяйству», «Кейс для размышления» (только релевантные);
- микро-урок = один навык + квиз сразу после.

**Практикум** — guided-проект на региональных данных + рамка «Проект на ВАШЕЙ земле» (слушатель применяет метод к своему хозяйству, артефакт — shareable: карта, план, отчёт). Для БПЛА-тем — готовые наборы снимков («дрон не обязателен»).

**`ai-assistant.md`** — ИИ-задание уровня модуля (no/low/pro-code по аудитории) с обязательным шагом верификации результата.

**Оценивание** — автопроверяемые квизы после микро-уроков + один сценарный кейс-вопрос; порог сертификации 75%.

!!! warning "Инварианты научной честности"
    Не выдумывать: суммы субсидий, цены, координаты, метрики моделей, нормы РК, DOI. Числа — только из проверяемых источников, иначе качественная формулировка или пометка `[UNVERIFIED]`.
