## С чего начать

| Вы… | Ваш маршрут |
|---|---|
| Фермер, руководитель МСБ | [П1](modules/p1/index.md) → [П2](modules/p2/index.md) → [П3](modules/p3/index.md), далее по задаче хозяйства |
| Агроном, технический специалист | [П2](modules/p2/index.md) → [П4](modules/p4/index.md) → [П7](modules/p7/index.md) |
| Специалист по воде | [П11](modules/p11/index.md) → [П12](modules/p12/index.md) |
| Студент бакалавриата/магистратуры | [Академические модули А1–А6](#catalog) |

Каждый модуль завершается **прикладным продуктом** — картой, планом, моделью или заявкой; аттестация с порогом 75% даёт [проверяемый сертификат](verify.md). Материалы доступны и [офлайн](offline.md).
