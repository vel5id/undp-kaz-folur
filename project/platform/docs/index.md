# Учебная платформа FOLUR Казахстан

**Устойчивое управление агроландшафтами Северного Казахстана: данные → ГИС → ИИ → применение.**

Платформа проекта UNDP-KAZ FOLUR (Food Systems, Land Use and Restoration). Исполнитель — НАО «Костанайский региональный университет им. А. Байтұрсынұлы».

!!! info "Статус: пилот (Этап 3)"
    Опубликовано полное содержание всех 21 модуля, работают самопроверка, pre/post-тестирование и сертификаты. Идёт подготовка пилотных потоков обучения.

## Как устроено обучение

- **6 академических модулей (А1–А6)** — для бакалавриата и магистратуры;
- **15 профессиональных модулей (П1–П15)** — краткосрочные программы 16–40 ак. часов для фермеров, агрономов и МСБ;
- принцип **«от инструмента к применению»**: каждый модуль завершается прикладным продуктом — картой, планом, моделью или заявкой;
- **ИИ-ассистент в каждом модуле**: ИИ-инструменты (Claude Code, OpenCode, GIS Copilot и аналоги) встроены в рабочий процесс — с обязательной верификацией результатов человеком;
- реальные открытые данные (Sentinel, Landsat, Google Earth Engine) и **уникальный батиметрический датасет** водоёмов Костанайской области;
- практикумы выполняются в Google Colab — установка ПО не требуется.
