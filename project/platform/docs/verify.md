# Проверка сертификата

Сертификаты аттестаций платформы содержат QR-код и текстовый код проверки. Отсканированный QR ведёт на эту страницу и заполняет поле автоматически; код можно вставить и вручную.

<div id="folur-verify"></div>

!!! warning "Границы проверки (важно для работодателя)"
    Проверка подтверждает **целостность кода** (контрольная сумма: данные не искажены и не набраны с опечаткой) и раскрывает содержимое сертификата: слушатель, аттестация, результат, дата.

    Это **не криптографическая подпись**: окончательное подтверждение — сверка с реестром слушателей проекта (KPI-журнал, подписанные листы регистрации). Выпуск криптографически верифицируемых сертификатов (Open Badges) предусмотрен при передаче платформы ПРООН.
