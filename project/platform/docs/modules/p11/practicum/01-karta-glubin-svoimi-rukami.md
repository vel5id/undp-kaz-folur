## Практикум: карта глубин и объём водоёма своими руками (по шагам)

<p>&gt;</p>

<p>Модуль П11: Батиметрия и мониторинг водных объектов. Guided-проект.</p>

<p>Инструменты: Google Colab (весь код дан готовым; альтернативный маршрут — QGIS). Только открытый стек.</p>

<p>Данные: <code>datasets/bathymetry-training-80k.csv</code> (уровень A) + контрольная сетка <code>bathymetry-grid-100m.tif</code> (уровень B) — см. Датасеты платформы.</p>

<p><a href="#python-practice">▶ Открыть встроенный редактор Python — шаг «Практика в Python»</a></p>

<p>Цель практикума</p>

<p><em>Самостоятельно</em> пройти полный конвейер обработки батиметрической съёмки — чистка с протоколом → карта глубин с изобатами → объём и кривая «уровень–площадь–объём» — на реальном датасете исполнителя, получив проверяемые артефакты и навык, переносимый на лог собственного эхолота.</p>

<p>Практикум собирает воедино лекцию 1 (как собраны данные), лекцию 2 (чистка и интерполяция) и лекцию 3 (объём и решения). Датасет — 80 000 сырых эхолотных промеров водохранилища степной зоны Казахстана: реальные полевые данные в локальной системе координат, без геопривязки.</p>

<p>Что нужно подготовить</p>

<p class="upgraded-list-item">Google-аккаунт и доступ к Google Colab — только для расширенной части на реальных данных (бесплатно; навык из П4, лекция 1). Учебный пример работает во встроенном редакторе без аккаунта;</p>

<p class="upgraded-list-item">учебный пример: встроенный редактор Python (<a href="#python-practice">шаг «Практика в Python»</a>);</p>

<p class="upgraded-list-item">файл <code>bathymetry-training-80k.csv</code> — скачивается из репозитория платформы (см. Датасеты);</p>

<p class="upgraded-list-item">контрольная сетка <code>bathymetry-grid-100m.tif</code> — для шага самопроверки;</p>

<p class="upgraded-list-item">(для маршрута QGIS) установленный QGIS (<a href="https://qgis.org">https://qgis.org</a>) — бесплатно, любая актуальная версия.</p>

<p>Задание</p>

<p>Шаг 1. Загрузка и разведка данных (10 мин)</p>

<p>Откройте ноутбук практикума в Colab и загрузите CSV через панель «Файлы» (значок папки слева → загрузка). Выполните ячейки раздела «Разведка»: они читают файл, печатают первые строки, число записей и сводные статистики, строят гистограмму глубин и карту точек, раскрашенную по глубине.</p>

```python
import pandas as pd
df = pd.read_csv("bathymetry-training-80k.csv")
print(len(df), "промеров")
df.describe()
```

<p>Ожидаемый результат: ровно 80 000 промеров; глубины от 0 до 16,1 м; на карте точек читаются параллельные галсы съёмки и их пересечения; на гистограмме — пик на нуле (нулевые отсчёты) и правый «хвост» больших глубин.</p>

<p>Запишите в текстовую ячейку три наблюдения: среднюю и медианную глубину, долю нулевых отсчётов, направление галсов.</p>

<p>Шаг 2. Чистка с протоколом (20 мин)</p>

<p>Выполните три ячейки раздела «Чистка» — по одной на каждый шаг конвейера лекции 2. Параметры каждого фильтра вынесены в начало ячейки — прочитайте их и осознанно подтвердите или измените:</p>

<p>Физический диапазон: нижний порог 0, верхний — с запасом от максимума водоёма (не «ровно 16,1»! — см. лекцию 2, §2.1);</p>

<p>Нули: правило медианы соседей — изолированный ноль среди значимых глубин удаляется, прибрежный сохраняется;</p>

<p>Выбросы: отклонение от медианы k ближайших соседей больше допуска.</p>

```python
# параметры фильтров — меняйте осознанно
MAX_DEPTH = 20.0   # м, физический предел с запасом
K_NEIGHBORS = 8    # соседей для локальной медианы
TOLERANCE = 2.5    # м, допуск отклонения от медианы
```

<p>Ожидаемый результат: протокол чистки — таблица «шаг → удалено точек → причина»; арифметика сходится (удалено + осталось = 80 000); чистая версия сохранена в новый файл <code>bathymetry-clean.csv</code>; карта удалённых точек показывает рассеянные одиночные точки, а не кластеры вдоль форм рельефа.</p>

<p>Если статистическая чистка удалила заметно больше ~1–2 % точек — вернитесь к параметрам: допуск слишком агрессивен.</p>

<p>Шаг 3. Интерполяция и карта глубин (20 мин)</p>

<p>Выполните раздел «Карта»: он строит из чистых точек регулярную сетку глубин (IDW; ячейка задана параметром — начните со 100 м, чтобы результат был сопоставим с контрольной сеткой) и рисует карту с изобатами через 2 м, легендой и подписью метода.</p>

<p>Ожидаемый результат: файл <code>depth-map.png</code> — карта глубин с изобатами; сетка сохранена как GeoTIFF <code>my-grid-100m.tif</code> (в локальной системе координат датасета). Изобаты плавные, повторяют форму чаши; максимум карты не превышает максимум чистых данных.</p>

<p><em>Маршрут QGIS (альтернатива без Colab):</em> импортируйте <code>bathymetry-clean.csv</code> как слой точек («Текст с разделителями», поля X/Y — <code>x_m</code>/<code>y_m</code>), затем «Обработка → Интерполяция → IDW» с ячейкой 100 м и постройте изобаты инструментом «Contour». Результат тот же; экспортируйте карту через макет печати.</p>

<p>Шаг 4. Объём и кривая «уровень–площадь–объём» (15 мин)</p>

<p>Выполните раздел «Объём»: метод призм по сетке (сумма глубина × площадь ячейки) и цикл «слива» по шагам 1 м для батиграфической кривой.</p>

<p>Ожидаемый результат: значение объёма при текущем уровне (в м³ и млн м³) и график кривой «уровень–площадь–объём» <code>curve.png</code>. По кривой ответьте письменно: какая доля объёма теряется при сработке уровня на первый метр?</p>

<p>Шаг 5. Самопроверка по контрольной сетке (10 мин)</p>

<p>Загрузите контрольную сетку уровня B и выполните раздел «Сверка»: разность вашей сетки и контрольной, статистика расхождений, карта разности.</p>

<p>Ожидаемый результат: расхождения малы в зонах плотных галсов и растут там, где галсы редки; форма вашей гипсографической кривой согласуется с контрольной. Опишите одним абзацем зоны низкого доверия вашей карты.</p>

<p>Самопроверка (критерии правильности):</p>

<p class="upgraded-list-item">протокол чистки сходится арифметически; исходный CSV не изменён;</p>

<p class="upgraded-list-item">нулевые прибрежные отсчёты сохранены (доля нулей в чистом файле не равна нулю);</p>

<p class="upgraded-list-item">диапазон сетки — в пределах диапазона чистых данных;</p>

<p class="upgraded-list-item">разность с контрольной сеткой не имеет систематического смещения по всей акватории (смещение везде в одну сторону — признак ошибки, например потерянной осадки датчика или сдвига координат);</p>

<p class="upgraded-list-item">ноутбук проходит «Restart &amp; Run all» без ошибок.</p>

<p>Продукт задания</p>

<p>По итогам практикума у вас должны быть:</p>

<p class="upgraded-list-item"><code>bathymetry-clean.csv</code> — очищенный датасет (+ протокол чистки в ноутбуке);</p>

<p class="upgraded-list-item"><code>depth-map.png</code> — карта глубин с изобатами, легендой и указанием метода;</p>

<p class="upgraded-list-item"><code>curve.png</code> — кривая «уровень–площадь–объём» + письменный вывод об объёме;</p>

<p class="upgraded-list-item">ноутбук целиком — он и есть протокол вашей работы (артефакт аттестации).</p>

<p>Применить к своему хозяйству.</p>

<p>Проект на ВАШЕЙ земле. Есть пруд, накопитель или доступ к водохранилищу? Снимите его по плану из лекции 1 (эхолот с записью лога + журнал + урез), конвертируйте лог в CSV <code>точка, x, y, глубина</code> — и прогоните через этот же ноутбук: меняются только имя файла и пороги фильтров. На выходе — карта глубин и кривая объёма вашего водоёма: основа плана полива, зарыбления и заявки на водохозяйственные мероприятия. Дрон и дорогие приборы не нужны; публиковать геопривязанные промеры не требуется (и не следует без проверки правового режима — Датасеты).</p>

<p>Дополнительные задания (по желанию)</p>

<p>Чувствительность к порогам: прогоните чистку с допуском выбросов 1,5 м и 4 м; сравните протоколы и карты разности — насколько итоговый объём чувствителен к параметру?</p>

<p>Сравнение методов: постройте сетку TIN (в QGIS — «TIN-интерполяция») и сравните с IDW по разности сеток: где методы расходятся и почему именно там?</p>
