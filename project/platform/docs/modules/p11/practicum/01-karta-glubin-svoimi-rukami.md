## Задание

### Шаг 1. Загрузка и разведка данных (10 мин)

Откройте ноутбук практикума в Colab и загрузите CSV через панель «Файлы» (значок папки слева → загрузка). Выполните ячейки раздела «Разведка»: они читают файл, печатают первые строки, число записей и сводные статистики, строят гистограмму глубин и карту точек, раскрашенную по глубине.

```python
import pandas as pd
df = pd.read_csv("bathymetry-training-80k.csv")
print(len(df), "промеров")
df.describe()
```

**Ожидаемый результат:** ровно 80 000 промеров; глубины от 0 до 16,1 м; на карте точек читаются параллельные галсы съёмки и их пересечения; на гистограмме — пик на нуле (нулевые отсчёты) и правый «хвост» больших глубин.

Запишите в текстовую ячейку три наблюдения: среднюю и медианную глубину, долю нулевых отсчётов, направление галсов.

### Шаг 2. Чистка с протоколом (20 мин)

Выполните три ячейки раздела «Чистка» — по одной на каждый шаг конвейера лекции 2. Параметры каждого фильтра вынесены в начало ячейки — прочитайте их и осознанно подтвердите или измените:

1. **Физический диапазон:** нижний порог 0, верхний — с запасом от максимума водоёма (не «ровно 16,1»! — см. лекцию 2, §2.1);
2. **Нули:** правило медианы соседей — изолированный ноль среди значимых глубин удаляется, прибрежный сохраняется;
3. **Выбросы:** отклонение от медианы k ближайших соседей больше допуска.

```python
# параметры фильтров — меняйте осознанно
MAX_DEPTH = 20.0   # м, физический предел с запасом
K_NEIGHBORS = 8    # соседей для локальной медианы
TOLERANCE = 2.5    # м, допуск отклонения от медианы
```

**Ожидаемый результат:** протокол чистки — таблица «шаг → удалено точек → причина»; арифметика сходится (удалено + осталось = 80 000); чистая версия сохранена в **новый** файл `bathymetry-clean.csv`; карта удалённых точек показывает рассеянные одиночные точки, а не кластеры вдоль форм рельефа.

Если статистическая чистка удалила заметно больше ~1–2 % точек — вернитесь к параметрам: допуск слишком агрессивен.

### Шаг 3. Интерполяция и карта глубин (20 мин)

Выполните раздел «Карта»: он строит из чистых точек регулярную сетку глубин (IDW; ячейка задана параметром — начните со 100 м, чтобы результат был сопоставим с контрольной сеткой) и рисует карту с изобатами через 2 м, легендой и подписью метода.

**Ожидаемый результат:** файл `depth-map.png` — карта глубин с изобатами; сетка сохранена как GeoTIFF `my-grid-100m.tif` (в локальной системе координат датасета). Изобаты плавные, повторяют форму чаши; максимум карты не превышает максимум чистых данных.

*Маршрут QGIS (альтернатива без Colab):* импортируйте `bathymetry-clean.csv` как слой точек («Текст с разделителями», поля X/Y — `x_m`/`y_m`), затем «Обработка → Интерполяция → IDW» с ячейкой 100 м и постройте изобаты инструментом «Contour». Результат тот же; экспортируйте карту через макет печати.

### Шаг 4. Объём и кривая «уровень–площадь–объём» (15 мин)

Выполните раздел «Объём»: метод призм по сетке (сумма глубина × площадь ячейки) и цикл «слива» по шагам 1 м для батиграфической кривой.

**Ожидаемый результат:** значение объёма при текущем уровне (в м³ и млн м³) и график кривой «уровень–площадь–объём» `curve.png`. По кривой ответьте письменно: какая доля объёма теряется при сработке уровня на первый метр?

### Шаг 5. Самопроверка по контрольной сетке (10 мин)

Загрузите контрольную сетку уровня B и выполните раздел «Сверка»: разность вашей сетки и контрольной, статистика расхождений, карта разности.

**Ожидаемый результат:** расхождения малы в зонах плотных галсов и растут там, где галсы редки; форма вашей гипсографической кривой согласуется с контрольной. Опишите одним абзацем зоны низкого доверия вашей карты.

**Самопроверка (критерии правильности):**

- [ ] протокол чистки сходится арифметически; исходный CSV не изменён;
- [ ] нулевые прибрежные отсчёты сохранены (доля нулей в чистом файле не равна нулю);
- [ ] диапазон сетки — в пределах диапазона чистых данных;
- [ ] разность с контрольной сеткой не имеет систематического смещения по всей акватории (смещение везде в одну сторону — признак ошибки, например потерянной осадки датчика или сдвига координат);
- [ ] ноутбук проходит «Restart & Run all» без ошибок.
