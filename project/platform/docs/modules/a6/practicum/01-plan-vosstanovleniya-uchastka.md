## Часть A. Диагноз деградации: тренд продуктивности (~35 мин)

### Шаг A1. Выбор участка и контрольной группы

Откройте [GEE Code Editor](https://code.earthengine.google.com). Найдите на карте участок в **вашем** районе (СКО, Костанайская или Акмолинская область), который подозреваете в деградации, — распахиваемая возвышенность, приозёрный контур, сбитое пастбище. Инструментом «Draw a shape» нарисуйте полигон `aoi`. Затем нарисуйте 2–3 контрольных полигона `ctrl1..ctrl3` на соседних участках **того же типа** (лекция 3, §2.3) — они нужны, чтобы отделить деградацию от климата.

### Шаг A2. Годовой ряд пиковой продуктивности (NDVI)

```javascript
// Годовой максимум NDVI (прокси продуктивности) за вегетацию, Landsat + Sentinel-2 по годам
var years = ee.List.sequence(2001, 2023);

function annualNDVI(geom) {
  return ee.FeatureCollection(years.map(function (y) {
    y = ee.Number(y);
    // Landsat 5/7/8/9 harmonized SR — длинный ряд; при желании замените на Sentinel-2 с 2016
    var col = ee.ImageCollection('LANDSAT/COMPOSITES/C02/T1_L2_ANNUAL_NDVI')
      .filter(ee.Filter.calendarRange(y, y, 'year'));
    var ndvi = col.first();  // годовой NDVI-композит
    var val = ndvi.reduceRegion({
      reducer: ee.Reducer.mean(), geometry: geom, scale: 30, maxPixels: 1e9});
    return ee.Feature(null, {year: y, ndvi: val.get('NDVI')});
  }));
}

var series_aoi = annualNDVI(aoi);
print(ui.Chart.feature.byFeature(series_aoi, 'year', 'ndvi')
  .setChartType('LineChart').setOptions({title: 'Годовая продуктивность участка (NDVI)'}));
```

**Ожидаемый результат:** график «год → NDVI» за 20+ лет: видна межгодовая изменчивость (влажные/сухие фазы) и, возможно, направленный тренд. Одиночные провалы — сухие годы или остаточная облачность; отметьте подозрительные точки.

### Шаг A3. Оценка тренда: наклон Тейла–Сена и значимость Манна–Кендалла

Экспортируйте ряды (`Export.table.toDrive`) и оцените тренд устойчивым методом (лекция 3, §2.2) в Colab:

```python
import numpy as np, pandas as pd
from scipy.stats import theilslopes, kendalltau

df = pd.read_csv('series_aoi.csv').dropna().sort_values('year')
years, y = df.year.to_numpy(float), df.ndvi.to_numpy(float)

slope, intercept, lo, hi = theilslopes(y, years)      # наклон Тейла–Сена + дов. интервал
tau, p = kendalltau(years, y)                          # значимость Манна–Кендалла (через тау)
print(f'Наклон Тейла–Сена: {slope:.5f} NDVI/год (90% ДИ {lo:.5f}..{hi:.5f})')
print(f'Манн–Кендалл: tau={tau:.3f}, p={p:.4f} -> '
      f'{"значимый тренд" if p < 0.05 else "тренд незначим"}')
```

**Ожидаемый результат:** ваши численные наклон и p (эталонного «правильного числа» нет — лекция 3, §2.2). Интерпретируйте: значимое отрицательное — кандидат в деградацию; незначимое — «стабильно или недостаточно данных».

### Шаг A4. Контроль климата: участок против контрольной группы и против осадков

```python

import matplotlib.pyplot as plt
for name in ['aoi', 'ctrl1', 'ctrl2', 'ctrl3']:

```

Дополнительно наложите годовые осадки ERA5-Land (каталог GEE, лекция [А4](../../a4/index.md)) и оцените, объяснимо ли снижение продуктивности осадками (упрощённый RESTREND, лекция 3, §2.3).

**Ожидаемый результат:** вывод в 3–4 предложениях: падает ли участок **избирательно** (соседи стабильны — признак деградации земли) или **синхронно** со всеми и объяснимо осадками (климатическая фаза). Это ядро диагноза.

## Часть B. Каркас биоразнообразия и очаги (~25 мин)

### Шаг B1. Картирование зелёной инфраструктуры

В GEE постройте летний NDVI Sentinel-2 высокого разрешения и найдите линейные объекты высокого NDVI среди пашни — лесополосы (лекция 2, §3.2):

```javascript
var s2 = ee.ImageCollection('COPERNICUS/S2_SR_HARMONIZED')
  .filterBounds(aoi).filterDate('2023-06-01', '2023-08-31')
  .filter(ee.Filter.lt('CLOUDY_PIXEL_PERCENTAGE', 20)).median();
var ndvi = s2.normalizedDifference(['B8', 'B4']).rename('NDVI');
Map.addLayer(ndvi.clip(aoi.buffer(2000)), {min: 0, max: 0.8,
  palette: ['white', 'yellow', 'green']}, 'NDVI лето');
```

Наложите слои OpenStreetMap (леса `landuse=forest`, водотоки `waterway`, дороги) — импортируйте через [QuickOSM в QGIS](https://qgis.org) или скачайте выборку с [OSM](https://www.openstreetmap.org). Отметьте: где лесополосы целы, где разорваны, есть ли буфер между пашней и водоёмами.

**Ожидаемый результат:** карта существующего каркаса с отмеченными разрывами и отсутствующими буферами.

### Шаг B2. Очаги деградации по типу

По NDVI-тренду (часть A) и спектральным признакам локализуйте очаги (лекция 3, §3.1): участки устойчиво низкого NDVI и открытой почвы (кандидаты в дефляцию), яркие пятна у бессточных понижений (кандидаты в засоление), очаги у водопоя/стоянок (перевыпас), ложбины стока к водоёму (водная эрозия). Отметьте их на карте как слой `очаги`.

**Ожидаемый результат:** карта очагов с предполагаемым типом каждого — с пометкой «гипотеза до полевой проверки» (лекция 3, §4.2).

## Часть C. Проект плана восстановления (~30 мин)

### Шаг C1. Соответствие «диагноз → практика»

Для каждого очага и разрыва каркаса подберите практику по таблице лекции 4, §1.2. Соберите таблицу в markdown-ячейке ноутбука или в QGIS-атрибутах:

| Очаг / элемент | Тип деградации | Практика | Восстанавливаемые услуги | Приоритет | Срок отдачи |
|---|---|---|---|---|---|
| (пример) склон у лога | водная эрозия, смыв | буферная полоса + залужение ложбины | чистая вода, защита почвы, −заиление | высокий | 1–2 сезона |
| (пример) возвышенная пашня | дефляция | ремонт лесополос + no-till | влага, защита почвы, углерод | средний | годы |
| (пример) понижение | засоление | фитомелиорация | продуктивность, почва | средний | годы |
| ... | ... | ... | ... | ... | ... |

### Шаг C2. Приоритизация и размещение по карте

Приоритизируйте строки по трём критериям (лекция 4, §3.1): скорость отдачи, затраты, предотвращение необратимых потерь. В QGIS разместите практики по карте (лекция 4, §3.2): буферы — вдоль водотоков и водоёмов; лесополосы — поперёк вредоносных ветров и в разрывы коридоров; фитомелиорация/залужение — на очаги; щадящий режим — в буферных зонах ООПТ и на уязвимых, ещё не потерянных землях. Экспортируйте карту размещения (`Проект → Импорт/Экспорт → Экспортировать карту в изображение`).

**Ожидаемый результат:** файл `restoration-map.png` — карта размещения практик, образующих связный каркас.
