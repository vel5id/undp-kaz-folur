# А3. ИИ и машинное обучение в агроэкологическом мониторинге

> **Тип:** Академический (бакалавриат/магистратура) · **Связь:** [П3](../p3/index.md), [П4](../p4/index.md) · **Компоненты FOLUR:** 1, 2, 3

## О модуле

Модуль формирует полный цикл компетенций применения машинного обучения (ML) и искусственного интеллекта (ИИ) к задачам агроэкологического мониторинга: от поиска открытых спутниковых данных до обоснованного выбора архитектуры модели и честной оценки её качества. Логика модуля — «от инструмента к применению»: сначала данные и их подготовка, затем модели, затем критическое сравнение подходов на реальной региональной задаче — классификации землепользования Северного Казахстана.

Три подхода, которые сравнивает слушатель, покрывают три типовые производственные ситуации: **Random Forest** — когда данных мало и нужна интерпретируемость; **MiniRocket** — когда есть многолетние ряды NDVI/EVI и важна скорость; **CNN (U-Net, ResNet)** — когда есть снимки высокого разрешения, GPU и размеченный датасет.

## Цели обучения

После прохождения модуля слушатель сможет:

1. **[Bloom: знать]** перечислять открытые источники данных дистанционного зондирования (Google Earth Engine, Microsoft Planetary Computer, Copernicus Data Space Ecosystem, архивы USGS/NASA — Landsat, MODIS, ASTER) и их ключевые характеристики (разрешение, периодичность, уровни обработки).
2. **[Bloom: понимать]** объяснять, как устроена подготовка обучающего датасета для ДЗЗ-задач (извлечение тайлов, разметка, аугментация, разбиение train/val/test) и почему пространственная утечка данных разрушает оценку качества модели.
3. **[Bloom: применять]** строить и валидировать модели трёх классов — Random Forest / Gradient Boosting, MiniRocket на временных рядах NDVI, CNN (U-Net, ResNet) — на снимках Sentinel-2 по Северо-Казахстанской области, используя открытый стек (Python, scikit-learn, PyTorch, Colab).
4. **[Bloom: анализировать]** сравнивать три подхода по метрикам (F1, IoU, каппа Коэна), интерпретировать матрицу ошибок и обосновывать выбор архитектуры под конкретную задачу хозяйства или акимата.
5. **[Bloom: анализировать]** проводить ревью ML-кода, сгенерированного ИИ-агентом: находить утечки данных, ошибки метрик и методические дефекты пайплайна (уровень ИИ-слоя — pro-code).

## Прикладной продукт модуля

**Классификация землепользования по Sentinel-2 для района Северо-Казахстанской области тремя подходами (RF / MiniRocket / CNN) со сравнительной таблицей метрик и обоснованием выбора архитектуры.** Артефакты: Jupyter-ноутбук, карты классификации, таблица сравнения F1/каппа, краткое письменное обоснование.

## ИИ-ассистент в работе · уровень Pro-code

Кодинг-агент (Claude Code / OpenCode) собирает ML-пайплайн «split → train → validate»; слушатель проводит ревью сгенерированного кода и целенаправленно ищет утечку данных и ошибки метрик. Задание и обязательный шаг верификации — в [ai-assistant.md](ai-assistant.md). Рамка платформы — [ИИ-инструменты в обучении](../../ai-tools.md).

*Правило: ИИ ускоряет — человек верифицирует. Все задания модуля выполнимы и без ИИ.*
