# Практикум: NDVI-паспорт поля и настроенный мониторинг

> Модуль **[П3: ИИ-инструменты без программирования](../index.md)**. Время выполнения: **60–90 мин**.
> Инструменты: браузер — Copernicus Browser (бесплатно) + агроплатформа с бесплатным уровнем (OneSoil или аналог). Программирование не требуется.
> Данные: Sentinel-2 L2A (Copernicus Data Space, бесплатная регистрация) — открытые и бесплатные; границы поля — свои из П2 или обводка по снимку.

## Цель практикума

**[Bloom: применять]** Пройти полный цикл модуля самостоятельно: от границы поля — через чтение карт и сезонной кривой NDVI — к **прикладному продукту модуля**: настроенному мониторингу поля в сервисе и «NDVI-паспорту поля» с заполненным шаблоном еженедельного отчёта.

Практикум собирает все три урока: [чтение NDVI](../lectures/01-chitaem-ndvi.md), [настройку мониторинга](../lectures/02-nastraivaem-monitoring.md), [проверку ИИ-аналитики](../lectures/03-proveryaem-servisy.md).

Модельная территория по умолчанию — полевые массивы в **Карабалыкском районе Костанайской области** (та же территория, что в [практикуме П2](../../p2/practicum/01-farm-map.md): массивы крупные, хорошо читаются). Допускается любой район СКО / Костанайской / Акмолинской области. Если у вас есть своё хозяйство — работайте сразу на нём.

!!! note "Применить к своему хозяйству"
    **Проект на ВАШЕЙ земле.** Все шаги одинаково работают на модельной территории и на вашей собственной. Если вы фермер или агроном — подставьте на шаге 1 границы своих полей (лучше всего — KML из практикума П2), а на шаге 6 заполните отчёт по реальному состоянию сезона. Тогда артефакт практикума — не учебная поделка, а действующий мониторинг вашего хозяйства с историей за прошлые сезоны, с которым вы уйдёте с курса. Именно этот вариант задуман как основной.

## Что нужно подготовить

- [ ] **Учётная запись Copernicus Data Space** — бесплатная регистрация на <https://dataspace.copernicus.eu/> (уже есть, если проходили П2).
- [ ] **Аккаунт в бесплатной агроплатформе** (OneSoil или аналог с бесплатным мониторингом полей) — регистрация по электронной почте.
- [ ] **Границы поля**: KML/GeoJSON из П2 — или готовность обвести одно поле по снимку прямо в сервисе.
- [ ] Пустой документ «NDVI-паспорт поля» (текстовый редактор или бумага) — структура появится по ходу шагов.
- [ ] 60–90 минут; делайте скриншоты на каждом шаге — они войдут в паспорт.

## Задание

### Шаг 1: выбираем поле и фиксируем границу (10 мин)

1. Выберите рабочее поле: своё — или модельное (крупный полевой массив в Карабалыкском районе, найдите по подложке).
2. Зафиксируйте границу: если есть KML из П2 — он и есть граница; если нет — найдите массив в Copernicus Browser и запомните его расположение (обводить будем на шаге 4 в агроплатформе).
3. Начните паспорт: запишите название поля, район, культуру (для модельного поля — `неизвестно`), источник границы.

**Ожидаемый результат:** первая страница паспорта заполнена; вы однозначно понимаете, о каком контуре пойдёт речь дальше.

### Шаг 2: свежая карта NDVI в Copernicus Browser (15 мин)

1. В Copernicus Browser найдите территорию поля; набор **Sentinel-2 L2A**.
2. Выберите свежую безоблачную сцену (фильтр облачности ~10–20%; проверьте глазами облака и тени именно над полем — [урок 1, §4](../lectures/01-chitaem-ndvi.md)).
3. Переключите визуализацию **True color → NDVI**. Осмотрите поле: равномерно ли, есть ли пятна, как выглядят края.
4. Сделайте два скриншота одной даты: NDVI и True color. Подпишите в паспорте дату сцены.
5. Полистайте 2–3 предыдущие безоблачные даты: устойчивы ли замеченные пятна.

**Ожидаемый результат:** в паспорте — пара скриншотов (NDVI + True color) с датой и 2–3 фразы: общее состояние, замеченные неоднородности, их устойчивость.

### Шаг 3: сезонная кривая по контуру (10 мин)

1. В Copernicus Browser нарисуйте контур поля инструментом выделения области (пентагон/полигон) — примерно по границе из шага 1.
2. Откройте статистику по области (функция графика/statistical info) для NDVI за текущий сезон: получите кривую среднего NDVI по датам.
3. Прочитайте кривую по четырём вопросам [урока 1, §3.1](../lectures/01-chitaem-ndvi.md): когда начался рост, какой высоты плато, есть ли провалы, была ли ступенька уборки (для прошлого сезона).
4. Скриншот кривой — в паспорт, с двумя-тремя выводами словами.

**Ожидаемый результат:** график сезонной кривой поля и его словесное чтение в паспорте. Это ваш **независимый эталон** для следующего шага.

### Шаг 4: регистрируем поле в агроплатформе (15 мин)

1. Войдите в агроплатформу. Заведите поле: загрузите KML — или обведите контур по снимку; если сервис предложил автограницу, примите её **только после сверки** со свежим снимком ([урок 2, §2](../lectures/02-nastraivaem-monitoring.md)).
2. Заполните атрибуты: название (как в паспорте), культура, сезон.
3. Откройте в платформе карту NDVI поля и сезонную кривую; полистайте историю прошлых лет, если она доступна.
4. Включите уведомления о новых снимках ([урок 2, §3](../lectures/02-nastraivaem-monitoring.md)).

**Ожидаемый результат:** поле зарегистрировано, культура указана, уведомления включены; скриншот экрана поля — в паспорт.

### Шаг 5: сверяем платформу с эталоном (10 мин)

Ключевой шаг практикума — верификация.

1. Найдите в платформе карту NDVI на дату, совпадающую (или ближайшую) со сценой шага 2.
2. Сравните с эталоном из Copernicus Browser: совпадает ли общий уровень, видны ли те же пятна в тех же местах, нет ли на карте платформы зон, отсутствующих в эталоне.
3. Сравните сезонную кривую платформы с кривой шага 3: та же форма, тот же момент максимума?
4. Запишите итог сверки в паспорт: «совпадает / расходится в том-то». Мелкие различия в оттенках нормальны (разные шкалы и палитры сервисов); расхождения в **расположении пятен или форме кривой** — повод разбираться (граница? даты? фильтр облаков?).

**Ожидаемый результат:** раздел паспорта «Сверка с независимым эталоном» заполнен; вы убедились (или обоснованно усомнились), что платформе можно верить.

### Шаг 6: проблемная зона и план проверки (10 мин)

1. Найдите на карте поля устойчивую неоднородность (или откройте автоматические зоны, если платформа их даёт на бесплатном уровне).
2. Проведите камеральную проверку по [уроку 3, §2](../lectures/03-proveryaem-servisy.md): устойчивость на датах, True color, наличие в эталоне.
3. Наметьте точки осмотра: 2–3 в зоне + 1–2 контрольные; выпишите их расположение в паспорт (для своего поля — как план реального выезда; для модельного — как учебный план).

**Ожидаемый результат:** в паспорте — описание зоны, итог камеральной проверки и план полевой проверки с точками «зона/контроль».

### Шаг 7: собираем паспорт и шаблон еженедельного отчёта (10–15 мин)

1. Сведите паспорт: титул (поле, район, культура, источник границы) → карта недели (скриншоты шага 2) → сезонная кривая и её чтение (шаг 3) → сверка платформы с эталоном (шаг 5) → зоны и план проверки (шаг 6).
2. Добавьте последний раздел — **шаблон еженедельного отчёта** из пяти блоков ([урок 2, §4](../lectures/02-nastraivaem-monitoring.md)): данные недели / общая картина / сигналы / решения / итоги проверок. Заполните его один раз по текущей неделе.
3. Сохраните паспорт как PDF или документ; положите в папку хозяйства рядом с материалами П1/П2, скриншоты — подпапкой.

**Ожидаемый результат:** готовый NDVI-паспорт поля (документ) + заполненный первый еженедельный отчёт.

## Продукт задания

По итогам практикума у вас должны быть:

- [ ] поле, зарегистрированное в агроплатформе: выверенная граница, культура, включённые уведомления;
- [ ] **NDVI-паспорт поля** (PDF/документ): скриншоты NDVI + True color с датами, сезонная кривая с чтением, раздел сверки с эталоном, зона с планом проверки;
- [ ] заполненный по текущей неделе шаблон еженедельного отчёта (5 блоков).

**Самопроверка (критерии зачёта):** у каждого скриншота указана дата сцены; чтение кривой отвечает на четыре вопроса урока 1; сверка «платформа ↔ Copernicus Browser» выполнена и её итог сформулирован; для зоны пройдена камеральная проверка и намечены контрольные точки вне зоны; в еженедельном отчёте нет ни одного числа или вывода, который нельзя проследить до скриншота или графика.

## Дополнительные задания (по желанию)

1. **История поля:** постройте в платформе (или в Browser по контуру) кривые за 2–3 прошлых сезона и сравните их между собой: какой сезон был лучшим и виден ли это по форме кривой.
2. **Второй сервис:** зарегистрируйте то же поле во второй бесплатной платформе и добавьте в паспорт короткое сравнение по матрице [урока 3, §4](../lectures/03-proveryaem-servisy.md) (данные, функции, экспорт).
3. **Полевой выход** (для своего поля): выполните план шага 6 на месте — фото точек «зона/контроль», диагноз, запись в пятый блок отчёта. Это первая строка вашей статистики доверия к сервису.
