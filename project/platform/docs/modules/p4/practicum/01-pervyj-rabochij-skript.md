### Шаг 6: Упаковка в функцию + Restart & Run all (≈8 мин)

Соберите шаги 3–4 в функцию-обработчик по образцу лекции 3 (§3.2):

```python
def pasport(fajl, d_min=0, d_max=17.0, porog_melko=2.0):
    """Паспорт одного CSV с промерами: чистка по диапазону + ключевые показатели."""
    df = pd.read_csv(fajl).drop_duplicates()
    clean = df[(df["depth_m"] >= d_min) & (df["depth_m"] <= d_max)]
    return {
        "fajl": fajl,
        "tochek": len(df),
        "udaleno": len(df) - len(clean),
        "sred": round(clean["depth_m"].mean(), 2),
        "maks": clean["depth_m"].max(),
        "dolya_melko": round((clean["depth_m"] < porog_melko).mean(), 3),
    }

print(pasport(RAW))
```

Затем — обязательная проверка воспроизводимости: **«Среда выполнения → Перезапустить и выполнить всё»** (Restart & Run all). Ноутбук должен пройти сверху донизу без ошибок.

**Ожидаемый результат:** словарь показателей, совпадающих с шагом 4; полный прогон без ошибок.
