# Практикум: карта цепочки и маркетинговый план модельного хозяйства

> Модуль **П15: Устойчивые цепочки и маркетинг**.
> ⏱ **Трудозатраты:** ~7 мин чтения + 60–90 мин практики.
> Инструменты: браузер Copernicus (Sentinel-2), OpenStreetMap, любой текстовый/табличный редактор (LibreOffice, Google Docs/Sheets), инструмент скриншотов — только открытый и бесплатный стек, установка ПО не требуется.
> Данные: открытые снимки Sentinel-2 (Copernicus Data Space Ecosystem), OpenStreetMap; каталог кейсов FOLUR и портал data.egov.kz — для справочной проверки. Собственные журналы и торговая практика хозяйства — если работаете по своей земле.

## Цель практикума

**[Bloom: применять]** Самостоятельно собрать прикладной продукт модуля: карту цепочки создания стоимости хозяйства на реальном космоснимке и данных OpenStreetMap, маркетинговый план «зелёной» продукции по шаблону модуля из шести разделов и реестр проверок — в форме, пригодной для переговоров с покупателем «зелёной» цепочки.

Практикум продолжает все три урока модуля ([1](../lectures/01-karta-cepochki-stoimosti.md), [2](../lectures/02-trassiruemost-i-markirovka.md), [3](../lectures/03-marketingovyj-plan.md)) и применяет их на реальных открытых данных Костанайской области (модельная территория; при желании — сразу на своём хозяйстве в СКО/Костанайской/Акмолинской области).

## Что нужно подготовить

- [ ] Браузер Copernicus: откройте <https://dataspace.copernicus.eu/> → Copernicus Browser (базовый просмотр доступен сразу; для полного функционала может потребоваться бесплатная регистрация).
- [ ] OpenStreetMap: <https://www.openstreetmap.org/> — без регистрации.
- [ ] Каталог кейсов FOLUR (ссылка в [библиографии модуля](../index.md)) — раздел о «зелёных» цепочках Казахстана.
- [ ] Пустой документ «Маркетинговый план» и пустая таблица (структуры — в шагах 4–6).
- [ ] Инструмент скриншотов вашей ОС для аннотированной карты.
- [ ] Если работаете по своему хозяйству: журналы полей, данные о текущих покупателях и торговых условиях.

## Задание

### Шаг 1: выберите модельное хозяйство и его «зелёное» предложение (10 мин)

Откройте Copernicus Browser, найдите зерновой пояс Костанайской области (поиск «Костанай», затем сместитесь к массивам крупных прямоугольных полей) и выберите летний безоблачный снимок Sentinel-2 (True color). Выберите **модельное хозяйство** — компактную группу из 6–10 смежных полей. Точные координаты нигде не записывайте — работаем с обликом территории, а не с адресом.

Задайте модельному хозяйству легенду «зелёного» предложения (пометьте в документе «модельные данные»): культуры (например, пшеница + чечевица), документированные практики (например, no-till третий год, журналы ведутся), статус (сертификата нет). Если работаете по своей земле — берите факты из своих журналов.

**Ожидаемый результат:** абзац «Продукт и подтверждения» (раздел 1 плана): что производим и какие «зелёные» свойства чем подтверждаются — по дисциплине [Урока 2, §3](../lectures/02-trassiruemost-i-markirovka.md): ни одного свойства без носителя-документа.

!!! note "Применить к своему хозяйству"
    **Проект на ВАШЕЙ земле.** Если у вас есть своё хозяйство — пропустите модельную легенду и с этого шага работайте по собственным полям и журналам: все последующие шаги идентичны, а результатом станет не упражнение, а первая редакция реального маркетингового плана. Свои точные координаты, кадастровые номера и финансовые условия в публикуемые версии документов не выносите — для переговоров достаточно рабочей копии.

### Шаг 2: слой производства — что видит покупатель на снимке (10 мин)

Пройдите по территории модельного хозяйства на летнем и весеннем снимках и соберите визуальный материал для «истории продукта» ([Урок 3, §2](../lectures/03-marketingovyj-plan.md)):

1. полосность и разнообразие культур (признак севооборота — [П9](../../p9/index.md));
2. лесополосы и природные элементы вокруг полей (элементы устойчивого ландшафта — [П5](../../p5/index.md));
3. состояние соседних территорий (однородная интенсивная пашня / залежи / пастбища).

Сделайте 2–3 скриншота с подписями «что здесь видно и какую практику это иллюстрирует». Это честный визуальный материал: снимок показывает то, что есть, — ровно поэтому он убедителен для покупателя.

**Ожидаемый результат:** 2–3 подписанных скриншота для истории продукта.

### Шаг 3: слой логистики — цепочка на карте OSM (15 мин)

Откройте OpenStreetMap на том же районе. Найдите и выпишите таблицей:

- ближайшие элеваторы/зернохранилища и железнодорожные станции (если объект не подписан тегами — берите ближайший райцентр как логистическую точку);
- дороги с твёрдым покрытием от хозяйства до этих точек и примерные плечи доставки;
- населённые пункты на маршруте вывоза.

**Ожидаемый результат:** таблица «объект → примерное плечо → качество дороги (по классу в OSM)» — 3–5 строк. Это фактура для звеньев 2–3 карты цепочки и для слагаемого «затраты канала» в ценовой логике.

### Шаг 4: карта цепочки стоимости (15 мин)

Соберите главный визуальный артефакт. На скриншот снимка (шаг 2) или простую схему поверх него нанесите шесть звеньев цепочки из [Урока 1, §1.1](../lectures/01-karta-cepochki-stoimosti.md): поле → ток/склад → консолидация/трейдер → переработка/экспорт → дистрибуция → покупатель, с реальной географией из шага 3 там, где она есть.

Каждое звено пометьте одним из трёх статусов (легенда обязательна):

- 🟢 **создаёт ценность** — документированные практики (звено 1 при ведущихся журналах);
- 🟡 **передаёт ценность** — раздельный учёт и документы есть или достижимы;
- 🔴 **разрыв** — статус здесь теряется (сверьтесь со списком пяти типовых разрывов [Урока 1, §3](../lectures/01-karta-cepochki-stoimosti.md)).

Для каждого 🔴 допишите строку «разрыв → мера устранения → что уточнить» (цену меры не выдумывайте — она уходит в реестр проверок шага 6).

**Ожидаемый результат:** файл `karta-cepochki.png` (или PDF): звенья, статусы, логистические плечи, легенда и дата снимка — читается без устных пояснений.

### Шаг 5: маркетинговый план — разделы 2–5 (20 мин)

В документе плана заполните по шаблону [Урока 3, §4](../lectures/03-marketingovyj-plan.md):

1. **Сегмент и канал** (раздел 2): выберите сегмент по правилу «требования уже закрываются документами, путь без неустранимых разрывов» ([Урок 3, §1](../lectures/03-marketingovyj-plan.md)); выпишите 2–3 покупателей-кандидатов типами (например, «программа "зелёной" цепочки из каталога FOLUR», «региональный переработчик с устойчивой линейкой») — без выдуманных названий компаний.
2. **Позиционирование и история продукта** (раздел 3): по формуле «[продукт] для [сегмент] — [подтверждаемое отличие], что подтверждено [документ]»; приложите скриншоты шага 2. Прогоните формулировку через все четыре пункта теста на проверяемость ([Урок 2, §3](../lectures/02-trassiruemost-i-markirovka.md)) и зафиксируйте результат прогона.
3. **Ценовая логика** (раздел 4): таблица «слагаемое → значение или "в реестр проверок" → источник» по формуле базовая цена + надбавка − затраты соответствия − затраты канала. Для модельного хозяйства значения остаются символьными («базовая цена — из торговой практики», «надбавка — из переговоров») — **числа не выдумываются**.
4. **Коммуникации** (раздел 5): 3–4 инструмента из [Урока 3, §3](../lectures/03-marketingovyj-plan.md) с календарём на сезон и ответственным; первым пунктом соберите состав «пакета покупателя».

**Ожидаемый результат:** документ плана с заполненными разделами 1–5; в разделе 4 нет ни одного числа без источника.

### Шаг 6: метрики и реестр проверок (10 мин)

Завершите план разделом 6:

- **метрики сезона** — 4–6 проверяемых событий (отправленные пакеты, письменные требования покупателей, протоколы о намерениях, доля партий с паспортом партии, замечания проверок) с целевыми значениями, которые вы назначаете сами;
- **реестр проверок** — таблица «утверждение → где проверить → статус» со всеми строками, накопленными в шагах 4–5: требования и надбавки покупателей (только письменно), условия элеватора по раздельному хранению, правила публичных заявлений и маркировки (adilet.zan.kz, документы схемы, ITC Standards Map), рыночные ориентиры (свежий FiBL/IFOAM).

**Ожидаемый результат:** план завершён; в реестре ≥6 строк, каждая с конкретным первоисточником проверки.

## Продукт задания

По итогам практикума у вас должен быть:

- [ ] `karta-cepochki.png` (или PDF) — карта цепочки со статусами звеньев, разрывами и логистикой;
- [ ] документ «Маркетинговый план» — шесть разделов по шаблону модуля, включая позиционирование с прогоном через тест на проверяемость;
- [ ] реестр проверок — ≥6 строк с первоисточниками;
- [ ] 2–3 подписанных скриншота для истории продукта.

**Самопроверка:** (1) каждое звено карты имеет статус, каждый 🔴 — меру устранения; (2) в плане нет ни одного числа и ни одного «зелёного» заявления без указанного источника/документа — проверьте поиском по документу слов «примерно», «обычно», «около»; (3) позиционирование проходит все 4 пункта теста; (4) каждая метрика — событие с документальным следом, а не ощущение.

## Дополнительные задания (по желанию)

1. Постройте карту цепочки для второго сегмента (например, сегмент 3 — внутренний переработчик) и сравните ценовую логику двух сегментов по формуле — где меньше новых затрат соответствия?
2. Повторите шаги 2–4 для хозяйства в другом регионе модуля (СКО или Акмолинская область) и отметьте, как меняются логистические плечи и статусы звеньев.
3. Соберите «пакет покупателя» (раздел 5, инструмент 1) как единый PDF: предложение + позиционирование + карта цепочки + образец паспорта партии ([Урок 2, §1.1](../lectures/02-trassiruemost-i-markirovka.md)).
