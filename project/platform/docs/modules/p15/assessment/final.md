# Итоговая аттестация модуля П15

> ⏱ **Трудозатраты:** ~35 мин (квиз + сценарный кейс).

<p>Модуль П15: Устойчивые цепочки и маркетинг.</p>

<p>Формат: 11 MCQ + 1 сценарный кейс · Порог сертификации — 75% (по сумме квиза и кейса).</p>

<p>К аттестации предъявляются: пакет практикума (карта цепочки, маркетинговый план, реестр проверок) и материалы ИИ-задания (таблица верификации, журнал отличий).</p>

<p>Часть 4. Сценарный кейс</p>

<p>Кейс оценивается экспертом по критериям ниже. Это образец сценарной части экзамена: в тест-движке платформы каждому слушателю генерируется индивидуальный вариант той же структуры.</p>

<p>Сценарий. Хозяйство в Северо-Казахстанской области: пшеница и чечевица, документированный no-till четвёртый год, учёт по П1, собственный склад с возможностью раздельного хранения, сертификатов нет. Маркетинговое агентство предложило хозяйству пакет «Эко-бренд под ключ»: логотип с колосом и надписью «Экологически чистый продукт Северного Казахстана», сайт с текстом «наша продукция выращена без химии на девственных землях», таргетированную рекламу и участие в продуктовой выставке. Агентство ссылается на «рост рынка эко-продуктов на 25% в год» и обещает «премию к цене до 30%». Параллельно на региональном мероприятии хозяйству предложили вступить в кооперационную программу «зелёных» закупок с письменными требованиями: журналы практик за 3 года, паспорта партий, право проверки, надбавка — по итогам квалификации поставщика.</p>

<p>Задание (ответ — связным текстом, 400–600 слов):</p>

<p>Прогоните предложение агентства через тест на проверяемость (Урок 2, §3) — по всем четырём пунктам для каждого заявления; назовите риски, которые хозяйство примет на себя вместе с «эко-брендом».</p>

<p>Проверьте «рыночные факты» агентства методом модуля: что делать с «25% в год» и «премией до 30%» до принятия любых решений (Урок 3, §4; ИИ-задание, чек-лист п. 3)?</p>

<p>Сравните два предложения через карту цепочки и сегментацию (Урок 1, §3; Урок 3, §1): какое из них имеет путь без разрывов при текущих документах хозяйства?</p>

<p>Сформулируйте решение: последовательность шагов на ближайший сезон, позиционирование по формуле модуля (Урок 3, §2) и 3 строки реестра проверок до подписания чего-либо.</p>
