# А2. Геоинформатика и пространственный анализ

> **Тип:** Академический · **Связь:** [П2 (Введение в ГИС)](../p2/index.md), [П7 (ДЗЗ и БПЛА)](../p7/index.md) · **Компоненты FOLUR:** 1 (ILM-политики и потенциал), 2 (устойчивые практики)
> Проект UNDP-KAZ FOLUR · НАО «КРУ им. А. Байтұрсынұлы»

Модуль даёт полный цикл геоинформационных компетенций: от моделей пространственных данных и проекций — через QGIS и Python-стек — к пространственному анализу и интеграции спутниковых и БПЛА-данных с ИИ-инструментами. Логика модуля — «от инструмента к применению»: каждая лекция завершается работой на реальных открытых данных Северного Казахстана, а модуль в целом — прикладным продуктом.

## Цели обучения

После прохождения модуля слушатель сможет:

1. **[Bloom: знать]** перечислять модели пространственных данных (вектор, растр), их форматы (GeoPackage, GeoTIFF, GeoJSON, Shapefile), основные системы координат (WGS84, UTM, казахстанские СК) и правила топологической корректности.
2. **[Bloom: понимать]** объяснять, как выбор проекции, разрешения и модели данных влияет на результат измерений площади и расстояния, и почему топологические ошибки искажают пространственный анализ.
3. **[Bloom: применять]** выполнять базовые операции геообработки — буферизацию, оверлей, интерполяцию (IDW/кригинг), зональную статистику — в QGIS и в Python-стеке (GeoPandas, Shapely, Rasterio) на открытых данных СКО, Костанайской и Акмолинской областей.
4. **[Bloom: анализировать]** сравнивать результаты, полученные разными методами (ручная цепочка в QGIS против скрипта GeoPandas, IDW против кригинга, спутниковый слой против ортофото БПЛА), и находить причины расхождений.
5. **[Bloom: анализировать]** проводить ревью геопайплайна, сгенерированного ИИ-агентом (Claude Code / OpenCode, GIS Copilot), и верифицировать его результат независимым способом.

## Прикладной продукт модуля

**Карта землепользования района Северо-Казахстанской области**, собранная в QGIS на открытых данных (ESA WorldCover, OpenStreetMap, Sentinel-2) с подложкой ортофотоплана БПЛА (готовый набор снимков — дрон не обязателен), с зональной статистикой классов землепользования по границам района. Продукт — shareable: экспортированная карта (PDF/PNG) + проект GeoPackage.

## ИИ-ассистент в работе · уровень Pro-code

GIS Copilot строит цепочку геообработки из текстового описания; Claude Code пишет GeoPandas-скрипт зональной статистики — результат сверяется с ручным расчётом в QGIS. Полное задание — в [ИИ-ассистенте модуля](ai-assistant.md).

*Правило: ИИ ускоряет — человек верифицирует. Все задания модуля выполнимы и без ИИ.*
