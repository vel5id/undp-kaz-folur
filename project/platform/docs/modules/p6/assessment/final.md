> Модуль **П6: Оценка экосистемных услуг хозяйства** · ⏱ ~35 мин

## Сценарный кейс (экспертная проверка)

**Ситуация.** Хозяйство в Есильском районе Северо-Казахстанской области (зерновое с рапсом; крупные поля, разбитые старыми полезащитными лесополосами; в понижении — заиленный пруд; вдоль восточной границы — балка с распаханными до бровки склонами, весной по ней уходит талая вода) готовит отчёт об экосистемных услугах для собственного планирования и для заявки на поддержку восстановления. Часть лесополос разрежена; удалённые углы рапсовых полей далеки от природных местообитаний. Бюджет ограничен — восстановить можно один-два приоритетных участка.

**Задание (12–15 предложений).** Составьте план отчёта и приоритеты:

1. Инвентаризация: назовите не менее пяти природных активов территории, для каждого — класс услуг по MEA, конкретную услугу и получателя (урок 1);
2. по каждой из трёх регулирующих услуг (опыление, защита от эрозии, удержание воды) укажите, по каким открытым данным и прокси-признакам вы её картируете и где на этой территории она в дефиците (урок 2);
3. дайте «светофорную» оценку состояния услуг и качественно свяжите красные/жёлтые позиции с долгосрочной рентабельностью — **без выдуманных сумм и норм** (урок 3);
4. выберите 1–2 приоритетных участка для восстановления и обоснуйте приоритет через число услуг и получателей, которые он закрывает («горячая точка»).

**Критерии оценивания:** корректная инвентаризация с привязкой «актив → услуга (верный класс MEA) → получатель» и отбраковкой услуг, которых нет (уроки 1–2); верные прокси и открытые данные для трёх услуг, указание дефицитных мест (урок 2); «светофор» и качественная связь с рентабельностью без денежных цифр «от себя» (урок 3, §1); приоритизация через «горячие точки» — один актив, закрывающий несколько услуг (урок 2, §5). Выдуманные суммы, «нормы РК» (отступы, радиусы, коэффициенты) без официального источника и услуги-фантомы снижают оценку — принцип научной честности модуля действует и на экзамене.
