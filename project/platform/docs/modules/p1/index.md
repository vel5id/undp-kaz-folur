# П1. Управление данными в агрохозяйстве

> **Тип:** Профессиональный, 16–24 ч · **Связь с А-модулями:** [А1 (жизненный цикл данных в агросфере)](../a1/index.md) · **Аудитория:** практики (фермеры, агрономы, МСБ) · **Компоненты FOLUR:** 1, 2
> **ИИ-слой:** уровень No-code (чат-ассистенты) · **Стек:** только бесплатный (Google Sheets/LibreOffice, QGIS, QField, GeoPackage)

Модуль открывает блок «Данные» профессиональной линейки. Его предмет — самый недооценённый актив хозяйства: собственные записи. Слушатель учится организовывать сбор данных так, чтобы каждый замер сохранял обязательные атрибуты (координаты, время, условия), вести структурированные журналы в бесплатных инструментах, защищать данные резервным копированием и грамотно передавать их партнёрам. Модуль — практический «спутник» академического [А1](../a1/index.md): та же логика жизненного цикла данных, но на уровне ежедневных действий хозяйства, без программирования и затрат.

## Цели модуля

После прохождения модуля слушатель сможет:

1. **[Bloom: понимать]** объяснять, почему запись без координат, даты и условий теряет ценность, и какие атрибуты замера являются невосстановимыми.
2. **[Bloom: применять]** вести журналы учёта хозяйства по правилам «чистой таблицы»: справочник полей с постоянными ID, словари значений, проверка ввода — в бесплатных инструментах (Google Sheets/LibreOffice, QField, GeoPackage).
3. **[Bloom: применять]** настраивать цикл резервного копирования по правилу 3-2-1 с назначенным ответственным и сезонным тестом восстановления.
4. **[Bloom: анализировать]** сравнивать классы бесплатных инструментов хранения (онлайн-таблицы, полевые геоприложения, локальная база) и выбирать комбинацию под условия хозяйства — включая работу без интернета.
5. **[Bloom: анализировать]** оценивать запросы на передачу данных (подрядчик, кооператив, платформа) по чек-листу — состав, формат, персональные и коммерчески чувствительные сведения, письменные условия — и верифицировать структуры журналов, предложенные ИИ-ассистентом, по чек-листу модуля.

## Прикладной продукт модуля

**Готовый шаблон системы учёта для хозяйства слушателя**: таблица со справочником полей, тремя журналами (наблюдения, операции, склад) и словарями с проверкой ввода; GeoPackage с оцифрованной по открытым данным (OSM/Sentinel-2) границей поля; паспорт данных с регламентом резервного копирования; первый архив 3-2-1. Продукт создаётся в [практикуме](practicum/01-shablon-sistemy-uchyota.md) на данных слушателя («Проект на ВАШЕЙ земле») и предъявляется на аттестации вместе с таблицей верификации [ИИ-задания](ai-assistant.md).

## Выходные компетенции

- Дисциплина записи полевых данных: обязательные атрибуты, форматы, правило черновика.
- Самостоятельное ведение системы учёта хозяйства в бесплатных инструментах — без программиста и абонентской платы.
- Защита данных (3-2-1, тест восстановления, передача дел) и контролируемая передача партнёрам (паспорт данных, открытые форматы, чек-лист условий).
- Работа с ИИ-ассистентом по рамке «ИИ ускоряет — человек верифицирует»: приёмка сгенерированных структур по чек-листу, отбраковка выдуманных «норм».

## Данные модуля

- OpenStreetMap — подложка для оцифровки границ (открыто).
- Sentinel-2 L2A — браузер Copernicus / Copernicus Data Space Ecosystem (открытый доступ) — визуальная сверка границ посевов.
- Учебный батиметрический датасет платформы (уровень A, обезличенный): `datasets/bathymetry-training-80k.csv` — образец полевого датасета с дисциплиной атрибутов и правилами передачи; политика доступа — [Датасеты платформы](../../datasets.md).

## Библиография и рамки

1. FAO. *The 10 Elements of Agroecology* — рамка агроэкологической трансформации; элемент «Co-creation and sharing of knowledge» опирается на сопоставимые, передаваемые данные. https://www.fao.org/agroecology/overview/overview10elements/
2. WOCAT — глобальная база технологий устойчивого землепользования; стандарт единообразного документирования практик. https://www.wocat.net/
3. ЦУР 15.3 / Land Degradation Neutrality (LDN) — целевая рамка нейтральности деградации земель; мониторинг требует многолетних сопоставимых данных. https://www.unccd.int/land-and-life/land-degradation-neutrality/overview
4. FOLUR Case Studies Catalogue, Vol. I (UNDP, декабрь 2025) — каталог региональных кейсов программы, включая «зелёные» цепочки поставок. https://www.undp.org/sites/g/files/zskgke326/files/2026-01/folur_case_studies_catalogue_volume_i_final_december2025__0.pdf
5. Документация QGIS (свободная ГИС). https://docs.qgis.org/
6. Документация QField (полевое приложение QGIS). https://docs.qfield.org/
7. Документация Sentinel-2 (ESA / Copernicus). https://sentinels.copernicus.eu/web/sentinel/missions/sentinel-2
8. Закон РК «О персональных данных и их защите» № 94-V от 21.05.2013 — рамка работы с персональными данными в журналах хозяйства.
9. Закон РК «О геодезии, картографии и пространственных данных» № 166-VII от 21.12.2022 — режим распространения пространственных данных. https://adilet.zan.kz/rus/docs/Z2200000166

    Модуль не воспроизводит детальные нормы и формы отчётности РК: правовые ориентиры даны качественно, с отсылкой к официальным источникам (adilet.zan.kz) — перед решениями сверяйтесь с действующими редакциями.
