# Практикум: собираем шаблон системы учёта хозяйства

> ⏱ **Трудозатраты:** 60–90 мин
> Модуль **П1: Управление данными в агрохозяйстве**, guided-проект.
> Инструменты: QGIS (бесплатно, qgis.org), Google Sheets или LibreOffice Calc, смартфон (по желанию — QField).
> Данные: OpenStreetMap (подложка), Sentinel-2 (браузер Copernicus, dataspace.copernicus.eu) — открытые и бесплатные.

## Цель практикума

**[Bloom: применять]** Собрать работающий каркас системы учёта: справочник полей с реальной оцифрованной границей, журналы с проверкой ввода по словарям, тестовые записи с полными атрибутами, паспорт данных и настроенный цикл резервного копирования. Это и есть **прикладной продукт модуля** — готовый шаблон, который после практикума заполняется данными вашего хозяйства.

Практикум применяет все три урока: [атрибуты замера](../lectures/01-atributy-zamera.md), [журналы и инструменты](../lectures/02-zhurnaly-i-instrumenty.md), [копии и передача](../lectures/03-rezervnye-kopii-i-peredacha.md).

## Что нужно подготовить

- [ ] Компьютер с установленной QGIS (свободная загрузка: qgis.org → Download; подойдёт версия LTR).
- [ ] Аккаунт Google (для Google Sheets) **или** LibreOffice Calc — если интернет неустойчив.
- [ ] 30–60 минут спокойного времени; смартфон — для необязательных шагов.
- [ ] Если у вас нет своего хозяйства — работайте с учебным участком: любое пахотное поле в вашем районе, видимое на снимке (границы полей Северного Казахстана отлично читаются на Sentinel-2).

!!! note "Применить к своему хозяйству"
    Это «Проект на ВАШЕЙ земле»: все шаги сформулированы так, чтобы результатом был шаблон **вашего** хозяйства — с вашими полями, вашими словарями операций и вашим регламентом копирования. Учебный участок используйте только если своего поля нет; логика и артефакты не меняются.

## Задание

### Шаг 1: справочник полей (10 мин)

Создайте таблицу (Google Sheets или LibreOffice Calc) с листом `Справочник_полей` и колонками:

```text
field_id | Название | Площадь_га | Культура_2026 | Примечание
P-01     | ...      | ...        | ...           | ...
```

Внесите 3–5 полей вашего хозяйства (или одно учебное). `field_id` — постоянный идентификатор: коротко, латиницей, с ведущим нулём (P-01…P-99), чтобы сортировка работала. Площадь пока можно оставить пустой — её даст шаг 2.

**Ожидаемый результат:** лист справочника с 3–5 строками и заполненными `field_id`.

### Шаг 2: оцифровка границы поля в QGIS по открытым данным (20–25 мин)

1. Откройте QGIS → новый проект. В панели «Браузер» разверните **XYZ Tiles → OpenStreetMap** и перетащите в карту — появилась бесплатная подложка.
2. Найдите ваше поле: инструмент поиска по координатам (панель «Локатор», внизу слева — введите широту и долготу усадьбы из [Урока 1, §2.1](../lectures/01-atributy-zamera.md)) или простое приближение колесом мыши.
3. Для уверенной оцифровки границ посевов откройте в соседней вкладке браузер Copernicus (dataspace.copernicus.eu → Browser), найдите тот же участок на безоблачном летнем снимке Sentinel-2 — границы полей на нём читаются лучше, чем на карте OSM. Сверяйтесь с ним при рисовании.
4. Создайте слой: Слой → Создать слой → **Новый слой GeoPackage**. Файл `hozyaystvo.gpkg`, имя таблицы `polya`, тип геометрии «Полигон», система координат EPSG:4326. Добавьте текстовое поле `field_id`.
5. Включите режим редактирования (карандаш) → «Добавить полигон» → обведите границу поля по подложке → в форме укажите `field_id` из справочника (P-01). Сохраните правки.
6. Площадь: откройте Свойства проекта → Общие → убедитесь, что эллипсоид для измерений включён; инструментом «Измерить площадь» (или калькулятором полей, выражение `$area`) получите площадь в гектарах и впишите её в справочник (шаг 1).

**Ожидаемый результат:** файл `hozyaystvo.gpkg` со слоем `polya`, в нём минимум один полигон с `field_id`, совпадающим со справочником; площадь перенесена в таблицу.

### Шаг 3: журналы с проверкой ввода (15–20 мин)

В той же таблице создайте три листа по образцам [Урока 2, §3](../lectures/02-zhurnaly-i-instrumenty.md):

- `Журнал_наблюдений`: Дата | field_id | Широта | Долгота | Тип | Оценка | Условия | Комментарий | Фото | Автор
- `Журнал_операций`: Дата | field_id | Вид_работы | Материал | Норма | Ед | Исполнитель
- `Склад`: Дата | Материал | Движение | Кол-во | Ед | field_id | Документ

Настройте словари (в Google Sheets: выделить колонку → Данные → Проверка данных → «Раскрывающийся список»; в LibreOffice: Данные → Проверка ячеек):

- `field_id` во всех журналах — список из диапазона справочника полей;
- `Тип` наблюдения: всходы / сорняки / вредители / вымочка / солонец / прочее;
- `Оценка`: норма / слабо / критично; `Условия`: сухо / после осадков / роса;
- `Вид_работы`: посев / культивация / опрыскивание / подкормка / уборка / прочее; `Движение`: приход / расход.

Заведите отдельный лист `Словари` и ссылайтесь на его диапазоны — так словари правятся в одном месте ([Урок 2, §3.1](../lectures/02-zhurnaly-i-instrumenty.md)).

**Ожидаемый результат:** три листа журналов; при вводе в словарные колонки выпадает список, произвольное значение помечается ошибкой.

### Шаг 4: пять тестовых записей с полными атрибутами (10 мин)

Внесите в `Журнал_наблюдений` пять записей — реальных или учебных. Координаты возьмите одним из способов: (а) со смартфона в поле, (б) в QGIS — щёлкните точку внутри вашего полигона правой кнопкой → «Копировать координату» → EPSG:4326, (в) долгим нажатием в картах смартфона. Каждая запись обязана пройти чек-лист атрибутов [Урока 1, §2](../lectures/01-atributy-zamera.md): дата ГГГГ-ММ-ДД, field_id, координаты в десятичных градусах (широта 50–55 для Северного Казахстана!), тип и оценка из словаря, условия, автор.

Проверка на карте: Слой → Добавить слой → «Добавить слой из текста с разделителями» → укажите экспортированный CSV журнала (Файл → Скачать → CSV), поля X = Долгота, Y = Широта. Точки легли **внутрь** вашего полигона? Если «уехали» — ищите переставленные широту/долготу.

**Ожидаемый результат:** пять точек наблюдений отображаются в QGIS внутри границы поля.

### Шаг 5 (по желанию): полевой сбор в QField (10 мин)

Если хотите автозапись координат: установите бесплатный QField на смартфон, скопируйте на него `hozyaystvo.gpkg` (или сохраните проект QGIS и перенесите папку проекта), откройте в QField, добавьте тестовую точку — координаты и время запишутся с GPS автоматически. Этот шаг не обязателен для зачёта практикума; полноценная настройка полевого проекта — материал модуля [П2](../../p2/index.md).

### Шаг 6: паспорт данных и цикл 3-2-1 (10 мин)

1. Создайте текстовый файл `PASPORT.md` (или лист `Паспорт` в таблице) по структуре [Урока 3, §3.1](../lectures/03-rezervnye-kopii-i-peredacha.md): что это, структура и словари, как собрано, ограничения, условия использования.
2. Выполните первый цикл копирования: скачайте таблицу целиком (Файл → Скачать → CSV/ODS), сложите в папку `ГГГГ-ММ-ДД_arhiv` вместе с `hozyaystvo.gpkg` и паспортом; скопируйте папку на второй носитель и в облако/на почту хозяйства.
3. Впишите в паспорт регламент: периодичность копирования, ответственный, дата следующего теста восстановления.

**Ожидаемый результат:** датированная папка-архив существует в трёх местах; паспорт заполнен.

## Продукт задания

По итогам практикума у вас должен быть **шаблон системы учёта хозяйства**:

- [ ] Таблица с 4+ листами: справочник полей, три журнала, словари (+паспорт);
- [ ] `hozyaystvo.gpkg` с оцифрованной границей минимум одного поля (`field_id` совпадает со справочником);
- [ ] 5 тестовых записей, отображающихся в QGIS внутри границы поля;
- [ ] `PASPORT.md` с регламентом резервного копирования;
- [ ] Первый архив 3-2-1 (папка с датой в трёх местах).

**Самопроверка:** главный критерий — тест чужими руками: человек, не участвовавший в работе, открыв паспорт и таблицу, понимает каждую колонку и может внести корректную запись, не спрашивая вас. Технический критерий — точки журнала лежат внутри полигона поля; словарные колонки не принимают произвольный текст.

## Дополнительные задания (по желанию)

1. Оцифруйте все поля хозяйства и раскрасьте их в QGIS по культуре сезона (Свойства слоя → Символика → Категоризированный по `Культура`).
2. Постройте первую сводку: в таблице — сводная таблица «число наблюдений по типу и полю»; обсудите с агрономом, что она показывает.
3. Пройдите [ИИ-задание модуля](../ai-assistant.md): адаптируйте словари и журналы под специфику вашего хозяйства с чат-ассистентом — и проверьте его предложения по чек-листу.
