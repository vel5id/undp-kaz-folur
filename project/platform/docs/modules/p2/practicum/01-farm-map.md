# Практикум: карта вашего хозяйства на подложке Sentinel-2

> Модуль **[П2: Введение в ГИС и открытые геоданные](../index.md)**. Время выполнения: **60–90 мин**.
> Инструменты: QGIS (свободный, кроссплатформенный) + браузер. Программирование не требуется.
> Данные: Sentinel-2 L2A (Copernicus Data Space, бесплатная регистрация), OpenStreetMap — всё открыто и бесплатно.

## Цель практикума

**[Bloom: применять]** Пройти полный цикл модуля самостоятельно: от пустого проекта QGIS до **прикладного продукта модуля** — карты хозяйства с оцифрованными границами полей на подложке космоснимка, экспортированной в PDF и KML.

Практикум собирает все три урока: [проект и подложку](../lectures/01-qgis-first-project.md), [открытый снимок](../lectures/02-open-data-sentinel.md), [оцифровку и выпуск карты](../lectures/03-digitize-and-map.md).

Модельная территория по умолчанию — окрестности села в **Карабалыкском районе Костанайской области** (полевые массивы хорошо читаются на снимке); допускается любой район СКО / Костанайской / Акмолинской области. Если у вас есть своё хозяйство — работайте сразу на нём (см. рамку «Применить к своему хозяйству»).

!!! note "Применить к своему хозяйству"
    **Проект на ВАШЕЙ земле.** Все шаги практикума одинаково работают на модельной территории и на вашей собственной. Если вы фермер или агроном — подставьте свой район на шаге 2, свои поля на шаге 5 и свои учётные площади на шаге 6. Тогда артефакт практикума — не учебная поделка, а рабочая карта вашего хозяйства, с которой вы уйдёте с курса. Именно этот вариант и задуман как основной.

## Что нужно подготовить

- [ ] **QGIS LTR** установлен ([урок 1, §2](../lectures/01-qgis-first-project.md)); плагины **QuickMapServices** и **QuickOSM** поставлены через «Модули → Управление модулями».
- [ ] **Учётная запись Copernicus Data Space** — бесплатная регистрация на <https://dataspace.copernicus.eu/>.
- [ ] Документы или учётные записи с площадями 2–3 полей — для сверки на шаге 6 (для модельной территории — пропустите сверку с документами, останется сверка визуальная).
- [ ] Папка `moya-ferma-gis/` с подпапками `data/` и `maps/`.
- [ ] 60–90 минут; сохраняйте проект после каждого шага (Ctrl+S).

## Задание

### Шаг 1: проект и система координат (5 мин)

1. Создайте проект QGIS и сохраните его как `moya-ferma-gis/ferma.qgz`.
2. Установите СК проекта по долготе территории: **EPSG:32641** (зона 41N) — западнее 66° в.д. (запад Костанайской области, включая Карабалыкский район), **EPSG:32642** (зона 42N) — восточнее (СКО, Акмолинская область).

**Ожидаемый результат:** пустой проект; в правом нижнем углу — код выбранной СК.

### Шаг 2: подложка и территория (5 мин)

1. Интернет → QuickMapServices → OSM → OSM Standard.
2. Найдите свою территорию (или модельную — Карабалыкский район) и приблизьтесь до масштаба, при котором видны полевые массивы.

**Ожидаемый результат:** карта района с сёлами и дорогами; вы уверенно находите рабочую территорию.

### Шаг 3: снимок Sentinel-2 (15 мин)

1. В Copernicus Browser (<https://dataspace.copernicus.eu/>) найдите ту же территорию.
2. Набор **Sentinel-2 L2A**, визуализация True color, фильтр облачности ~10–20%; выберите безоблачную сцену вегетационного периода ([урок 2, §3](../lectures/02-open-data-sentinel.md): проверьте глазами облака и их тени именно над рабочей территорией).
3. Скачайте видимую область как **GeoTIFF с геопривязкой** (высокое разрешение), охватив все будущие поля с запасом.
4. Сохраните файл как `data/sentinel2-<дата сцены>.tif` и перетащите его в QGIS.
5. Входной контроль ([урок 2, §4.1](../lectures/02-open-data-sentinel.md)): снимок совпадает с подложкой OSM по дорогам и сёлам; в свойствах слоя указана СК.

**Ожидаемый результат:** снимок с известной датой лежит в проекте точно под подложкой.

### Шаг 4: слой полей (5 мин)

1. Слой → Создать слой → **Создать слой GeoPackage…**: файл `data/polya.gpkg`, слой `polya`, геометрия — полигон, СК — СК проекта.
2. Поля таблицы: `name` (текст), `crop` (текст), `year` (целое), `area_ga` (десятичное).

**Ожидаемый результат:** пустой полигональный слой в панели слоёв.

### Шаг 5: оцифровка 3–5 полей (20–30 мин)

1. Включите режим редактирования слоя `polya` (жёлтый карандаш).
2. Инструментом «Добавить полигон» обведите по снимку 3–5 полевых массивов ([урок 3, §2](../lectures/03-digitize-and-map.md)): масштаб оцифровки 1:10 000–1:25 000, вершины по необходимости, граница — по фактической кромке на снимке.
3. Для смежных полей включите прилипание и «Избегать пересечений».
4. Заполняйте атрибуты при замыкании каждого контура: `name`, `crop`, `year` (для модельной территории культуру укажите как `неизвестно` — честнее, чем гадать).
5. Сохраните правки слоя и проект.

**Ожидаемый результат:** 3–5 полигонов точно по кромкам массивов; таблица атрибутов заполнена без пустых `name`.

### Шаг 6: площади и сверка (10 мин)

1. Таблица атрибутов → Калькулятор полей → обновить `area_ga` выражением `$area / 10000`.
2. Просмотрите значения: площади полевых массивов Северного Казахстана — обычно десятки–сотни гектаров. Значения вида 0,0002 — неверная СК слоя (вернитесь к шагу 4).
3. **Сверка с независимым источником:** сравните `area_ga` с документальной площадью хотя бы одного поля. Расхождение в единицы процентов — норма; больше — ищите ошибку контура ([урок 3, §4](../lectures/03-digitize-and-map.md)).
4. Пройдите по контурам на крупном масштабе: без самопересечений, недоводов, дублей.

**Ожидаемый результат:** колонка `area_ga` заполнена правдоподобными значениями; минимум одна площадь сверена с документами (или, для модельной территории, — с измерением линейкой).

### Шаг 7: оформление и компоновка (10–15 мин)

1. Символика слоя `polya` — «По значению» колонки `crop`; подписи — `name` (или составная подпись с площадью, [урок 3, §2.1](../lectures/03-digitize-and-map.md)).
2. Проект → Создать макет → соберите: карту, заголовок («Карта хозяйства …, сезон …»), легенду (без служебных подложек), масштабную линейку, стрелку севера.
3. Строка источников внизу: «Contains modified Copernicus Sentinel data <год>», «© участники OpenStreetMap», дата составления, автор.

**Ожидаемый результат:** компоновка отвечает на три вопроса — что, где, насколько верить.

### Шаг 8: экспорт продуктов (5 мин)

1. Макет → Экспорт в PDF → `maps/karta-hozyaystva.pdf`.
2. ПКМ по слою `polya` → Экспорт → Сохранить объекты как… → **KML** → `maps/polya.kml`, поле имени — `name`.
3. **Верификация KML:** откройте файл в Google Earth (веб-версия или приложение) — поля лежат на месте, подписи читаются.

**Ожидаемый результат:** PDF и KML в папке `maps/`; KML проверен в независимой программе.

## Продукт задания

По итогам практикума у вас должны быть:

- [ ] `ferma.qgz` — проект QGIS со снимком и слоем полей;
- [ ] `data/polya.gpkg` — 3–5 полигонов с заполненными `name`, `crop`, `year`, `area_ga`;
- [ ] `maps/karta-hozyaystva.pdf` — карта с легендой, масштабом и источниками;
- [ ] `maps/polya.kml` — проверен в Google Earth.

**Самопроверка (критерии зачёта):** снимок имеет известную дату и совпадает с подложкой; СК проекта и слоя — метровая зона UTM; площади правдоподобны и минимум одна сверена с независимым источником; на PDF присутствуют легенда, масштаб, стрелка севера и строка источников; KML открывается вне QGIS.

## Дополнительные задания (по желанию)

1. **История территории:** найдите в USGS EarthExplorer снимок Landsat вашей территории 1990-х годов и сравните с текущим: какие массивы появились, что заброшено.
2. **Слой окружения:** выгрузите QuickOSM дороги и водные объекты района, оформите и добавьте на компоновку вторым информационным слоем.
3. **WorldCover-контроль:** скачайте тайл ESA WorldCover и проверьте, что ваши поля попадают в класс «пашня»; найдите и объясните расхождения.
