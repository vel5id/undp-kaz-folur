# Профессиональные модули (П1–П15)

**15 краткосрочных программ по 16–40 академических часов** для фермеров, агрономов, технических специалистов и МСБ — в 5 тематических блоках. Каждый модуль завершается прикладным продуктом для вашего хозяйства; аттестация ≥75% даёт [сертификат с QR-проверкой](../verify.md).

Не знаете, с чего начать? Базовый цифровой трек: [П1](p1/index.md) → [П2](p2/index.md) → [П3](p3/index.md); подбор по роли — на [главной](../index.md). Академическая линейка А1–А6 — в [общем каталоге](index.md).
