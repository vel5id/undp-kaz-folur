# Итоговая аттестация модуля П5

> Модуль **П5: Ландшафтное планирование для МСБ** · ⏱ ~35 мин
> Формат: банк MCQ (автопроверка тест-движком платформы, индивидуальные варианты) + сценарный кейс (экспертная проверка).
> **Порог сертификации — 75%.** К аттестации предъявляется прикладной продукт [практикума](../practicum/01-landshaftnyj-plan.md) (карта зонирования PDF + GeoPackage + паспорт территории + дорожная карта) и журнал отличий из [ИИ-задания](../ai-assistant.md).

Вопросы сгруппированы по урокам; каждый привязан к разделу лекции (см. `explain`). Дистракторы отражают типичные реальные ошибки — читайте внимательно.

## Сценарный кейс (экспертная проверка)

> Образец сценарной части экзамена. Тест-движок платформы генерирует индивидуальные варианты кейса (другая область, другой набор элементов территории); проверка — экспертная, по критериям ниже.

**Ситуация.** Вы — руководитель зернового хозяйства в Костанайской области. Территория: массив пашни; через два поля проходит ложбина, впадающая в пресный пруд у границы землепользования; вдоль пруда местами пашут «до воды», у пруда — стихийный водопой; на юго-востоке — солонцовый клин, который сеют ежегодно с худшим результатом; из четырёх лесополос две — с большими разрывами; прошлой весной у края одного из полей удлинилась промоина. Консультант (или ИИ-ассистент) прислал вам черновик: **всю пашню оставить производственной зоной, вдоль пруда установить полосу «шириной 50 метров согласно законодательству», на все меры запросить субсидию, индикатор один — «улучшение состояния земель»**.

**Задание (ответ — 1–1,5 страницы прозой):**

1. Проведите элементы территории через решающее дерево зонирования: какие зоны вы выделите и почему (со ссылкой на рельеф, воду и состояние земель)?
2. Найдите и обоснуйте **не менее четырёх** ошибок присланного черновика — по чек-листам Урока 3 (§5.1) и ИИ-задания.
3. Составьте первый год дорожной карты: 3–4 меры с приоритизацией («эффект × стоимость» + правило необратимости), ответственными ролями и проверяемыми бесплатно индикаторами.

**Критерии оценки (эксперт):**

| Критерий | Что проверяется |
|---|---|
| Зонирование (30%) | Три типа зон присутствуют; ложбина и прибрежная полоса — буферы; солонцовый клин разобран как конфликт «доход против восстановления» |
| Разбор черновика (30%) | Найдены: непроверенная «ширина 50 м по законодательству» (требует проверки по официальному источнику), полная зависимость плана от субсидии, непроверяемый индикатор, игнорирование промоины/ложбины/солонца |
| Дорожная карта (30%) | Промоина — в году 1 по правилу необратимости; есть «быстрые победы»; каждая мера с местом, ролью и индикатором-фактом |
| Честность (10%) | Нет выдуманных сумм и нормативов; где нужны цифры — «оценить»/«проверить по официальному источнику» |

**Порог сертификации по модулю — 75%** суммарно по MCQ-банку и кейсу. К защите предъявляются: комплект практикума (карта PDF + GeoPackage + паспорт + дорожная карта) и журнал отличий из ИИ-задания.
