# Итоговая аттестация модуля П5

> Модуль **П5: Ландшафтное планирование для МСБ** · ⏱ ~35 мин

<p>Модуль П5: Ландшафтное планирование для МСБ · ⏱ ~35 мин</p>

<p>Формат: банк MCQ (автопроверка тест-движком платформы, индивидуальные варианты) + сценарный кейс (экспертная проверка).</p>

<p>Порог сертификации — 75%. К аттестации предъявляется прикладной продукт практикума (карта зонирования PDF + GeoPackage + паспорт территории + дорожная карта) и журнал отличий из ИИ-задания.</p>

<p>Вопросы сгруппированы по урокам; каждый привязан к разделу лекции (см. <code>explain</code>). Дистракторы отражают типичные реальные ошибки — читайте внимательно.</p>

<p>Сценарный кейс (экспертная проверка)</p>

<p>Образец сценарной части экзамена. Тест-движок платформы генерирует индивидуальные варианты кейса (другая область, другой набор элементов территории); проверка — экспертная, по критериям ниже.</p>

<p>Ситуация. Вы — руководитель зернового хозяйства в Костанайской области. Территория: массив пашни; через два поля проходит ложбина, впадающая в пресный пруд у границы землепользования; вдоль пруда местами пашут «до воды», у пруда — стихийный водопой; на юго-востоке — солонцовый клин, который сеют ежегодно с худшим результатом; из четырёх лесополос две — с большими разрывами; прошлой весной у края одного из полей удлинилась промоина. Консультант (или ИИ-ассистент) прислал вам черновик: всю пашню оставить производственной зоной, вдоль пруда установить полосу «шириной 50 метров согласно законодательству», на все меры запросить субсидию, индикатор один — «улучшение состояния земель».</p>

<p>Задание (ответ — 1–1,5 страницы прозой):</p>

<p>Проведите элементы территории через решающее дерево зонирования: какие зоны вы выделите и почему (со ссылкой на рельеф, воду и состояние земель)?</p>

<p>Найдите и обоснуйте не менее четырёх ошибок присланного черновика — по чек-листам Урока 3 (§5.1) и ИИ-задания.</p>

<p>Составьте первый год дорожной карты: 3–4 меры с приоритизацией («эффект × стоимость» + правило необратимости), ответственными ролями и проверяемыми бесплатно индикаторами.</p>
