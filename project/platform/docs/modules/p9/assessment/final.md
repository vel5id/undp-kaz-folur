<p>Сценарный кейс (проверяется экспертом)</p>

<p>Ситуация. Вы — агроном хозяйства в сухостепной подзоне Акмолинской области. Пять полей сопоставимой площади; история по журналам и NDVI: поля 1–3 — пшеница несколько лет подряд (на поле 3 засорённость заметно выше — «рваные» профили), поле 4 — химический пар прошлого сезона, поле 5 — солонцовый клин, стабильно худшие NDVI-профили. Хозяйство держит небольшое поголовье КРС; зимой концентраты и часть сена закупаются. Руководитель принёс вам схему от стороннего консультанта: «пятиполка: рапс → озимая пшеница → кукуруза на зерно → горох → подсолнечник, все поля стартуют с года 1, урожайность вырастет на 30–40%, на всё есть субсидии».</p>

<p>Задание (ответ — связным текстом, 300–500 слов):</p>

<p>Проведите схему консультанта по чек-листу модуля (Урок 3, §5): назовите не менее четырёх конкретных дефектов с указанием пункта чек-листа и урока, который его обосновывает.</p>

<p>Предложите свой вариант: длина ротации, звенья, стартовое звено каждого из пяти полей от фактической истории, решение по солонцовому клину и по кормовому дефициту.</p>

<p>Укажите, какие позиции вашего варианта требуют проверки по внешним источникам (региональные рекомендации, официальные условия мер поддержки) — сформулируйте их как вопросы, не называя цифр.</p>

<p>Критерии оценки (эксперт): найдены ключевые дефекты — влагоёмкие культуры для сухостепной подзоны без обоснования (пункт 1), старт «с чистого листа» без истории полей (пункт 5), выдуманные проценты урожайности и бездоказательные «субсидии» (пункт 6), отсутствие кормового звена при реальном кормовом дефиците (пункт 4), рискованная последовательность семейств/поздних культур (пункт 2); собственный вариант стартует от истории (поле 4 — под пшеницу; самое засорённое — в пар/лечение; солонец — выводное поле под залужение), содержит кормовое звено и корректные формулировки «проверить по источнику». Зачёт кейса — при ≥4 верно обоснованных дефектах и агрономически непротиворечивом собственном варианте.</p>

<p>Итог аттестации = квизы (автопроверка) + сценарный кейс (эксперт) + предъявленные артефакты практикума и ИИ-задания. Порог — 75%. Успешное прохождение фиксируется сертификатом платформы (QR-верификация).</p>
