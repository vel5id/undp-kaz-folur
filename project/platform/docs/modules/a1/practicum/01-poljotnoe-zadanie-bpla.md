<p><em>Практикум</em>: полётное задание БПЛА на модельный участок и сопоставление с Sentinel-2</p>

<p><em>Инструменты:</em> QGIS (свободный), браузер Copernicus (бесплатная регистрация CDSE), встроенный редактор Python или калькулятор — только открытый стек. Данные: OpenStreetMap (подложка), Sentinel-2 L2A (Copernicus Data Space Ecosystem) — открытые; дрон не требуется.</p>

<p><em><strong>Цель практикума</strong></em><em><strong>:</strong></em> самостоятельно спроектировать полётное задание БПЛА на модельный участок пашни в Северном Казахстане — от контура и целевого GSD до схемы маршрутов и оценки времени миссии — и обосновать выбор платформы, сопоставив ожидаемый результат съёмки с реальным снимком Sentinel-2 той же территории</p>

<p><em>Что нужно подготовить</em></p>

<p class="upgraded-list-item">QGIS (актуальная LTR-версия) — свободно, qgis.org; установка ~10 мин.</p>

<p class="upgraded-list-item">Аккаунт CDSE (dataspace.copernicus.eu) — бесплатная регистрация для просмотра и скачивания Sentinel-2.</p>

<p class="upgraded-list-item">(Для Шага 7) открытый ЦМР на район — Copernicus GLO-30 DEM (portal.opentopography.org) или SRTM 1 arc-sec; уклоны считаются в QGIS: «Растр → Анализ → Уклон». Слой земного покрова, если нужен, — ESA WorldCover (esa-worldcover.org).</p>

<p class="upgraded-list-item">Расчёты миссии: <a href="#python-practice">встроенный редактор Python — шаг «Практика в Python»</a> в конце этой страницы; устанавливать ничего не нужно (расчёты можно выполнить и вручную по формулам Урока 2).</p>

<p class="upgraded-list-item">Параметры условного учебного сенсора (из Урока 2): пиксель p = 3 мкм, фокусное f = 8 мм, матрица 4000 × 3000.</p>

## ЗАДАНИЕ

## Шаг 1: выбираем модельный участок (10 мин)

<p>Откройте QGIS → создайте новый проект → добавьте подложку OpenStreetMap (панель «Браузер» → XYZ Tiles → OpenStreetMap).</p>

<p>Установите систему координат проекта: для Костанайской области — UTM 41N (EPSG:32641) или 42N (EPSG:32642) в зависимости от долготы участка; для СКО и Акмолинской — 42N (правило — Урок 4, раздел 1).</p>

<p>Найдите на подложке массив пашни в одной из трёх областей проекта (СКО / Костанайская / Акмолинская — характерная прямоугольная нарезка полей хорошо видна). Создайте новый слой GeoPackage plot.gpkg (Слой → Создать слой → Новый слой GeoPackage, геометрия — полигон, СК — СК проекта) и оцифруйте контур модельного участка ~100–200 га (одно поле или его часть).</p>

<p><em>Ожидаемый результат:</em> файл plot.gpkg с одним полигоном; в свойствах слоя — корректная СК; площадь участка (Вектор → Инструменты геометрии или поле $area) в диапазоне 100–200 га.</p>

## Шаг 2: формулируем задачу съёмки и целевой GSD (10 мин)

<p>Выберите одну из двух легенд (или свою по согласованию с преподавателем):</p>

<p>A. Диагностика проблемной зоны: различать объекты от 10 см (колеи, огрехи, пятна сорняков) → минимальный различимый объект 0,10 м.</p>

<p>B. Картирование микрорельефа под влагонакопление: различать объекты от 30 см → минимальный различимый объект 0,30 м.</p>

<p>Рассчитайте целевой GSD по правилу «≥3 пикселя на объект» (Урок 2): GSD = объект / 3. Запишите задачу в одну фразу по шаблону обоснования (Урок 3, раздел 6.1): «различать X от N см на участке S га, однократно/регулярно».</p>

<p><em>Ожидаемый результат</em>: записанные значения: минимальный объект, целевой GSD (A: ~3,3 см; B: 10 см), формулировка задачи.</p>

## Шаг 3: рассчитываем параметры миссии (20 мин)

<p>Во <a href="#python-practice">встроенном редакторе Python</a> (или вручную) вычислите для условного сенсора:</p>

```python
p = 3e-6      # размер пикселя, м
f = 8e-3      # фокусное расстояние, м
W_px, L_px = 4000, 3000   # матрица, пикс
gsd = 0.033   # ваш целевой GSD из шага 2, м

H = gsd * f / p                    # высота полёта, м
W = W_px * gsd                     # захват поперёк маршрута, м
L = L_px * gsd                     # захват вдоль маршрута, м
side, forward = 0.70, 0.80         # перекрытия (равнина, Урок 2)
spacing = W * (1 - side)           # междурядье маршрутов, м
shutter = L * (1 - forward)        # интервал съёмки, м
print(H, W, L, spacing, shutter)
```


<p>Затем оцените миссию: измерьте в QGIS ширину и длину участка (инструмент «Измерить линию»), посчитайте число маршрутных линий N = ширина / spacing (округление вверх), суммарную длину Lmiss = N × длина + развороты (~15%) и время T = Lmiss / v при крейсерской скорости v = 8 м/с.</p>

<p><em>Ожидаемый результат</em>: таблица параметров миссии — GSD, H, перекрытия, spacing, интервал съёмки, N линий, длина, время. Контроль для легенды A на участке 1000×1500 м: H ≈ 88 м, spacing ≈ 40 м, N ≈ 25–26 линий (если ваш участок другой — числа пропорционально другие).</p>

## Шаг 4: строим схему маршрутов в QGIS (15 мин)

<p>Создайте линейный слой mission.gpkg (GeoPackage, линии, СК проекта). Постройте параллельные линии через рассчитанный spacing: проще всего — оцифровать первую линию вдоль длинной стороны участка, затем Правка → Копировать/Вставить со сдвигом, либо использовать инструмент «Массив смещённых линий» (Processing → «Array of offset (parallel) lines», параметр смещения = spacing). Обрежьте линии по полигону участка с буфером +30 м на развороты (Processing → «Обрезать»).</p>

<p>Оформите карту: подложка OSM, контур участка, маршруты, стрелка севера, масштабная линейка (Проект → Создать макет) → экспортируйте mission-map.pdf.</p>

<p><em>Ожидаемый результат</em>: mission.gpkg с N параллельных линий внутри участка (+буфер) и карта mission-map.pdf.</p>

## Шаг 5: скачиваем фрагмент Sentinel-2 и сопоставляем (15 мин)

<p>В браузере CDSE (dataspace.copernicus.eu → Browser) найдите свежую малооблачную (&lt;20%) сцену Sentinel-2 L2A на ваш участок в вегетационный период. Задокументируйте: дату, идентификатор сцены, облачность (метаданные сцены). Скачайте True Color изображение области участка (кнопка экспорта изображения с геопривязкой) и добавьте GeoTIFF в проект QGIS.</p>

<p>Приблизьте участок и честно сравните: что видно на 10-метровом пикселе (зоны, границы, крупные неоднородности) и чего не видно (объекты вашей легенды — колеи, пятна от 10–30 см). Сделайте два скриншота одного и того же фрагмента: Sentinel-2 и подложка OSM/план миссии.</p>

<p><em>Ожидаемый результат</em>: GeoTIFF фрагмента Sentinel-2 в проекте; записанные дата/ID/облачность сцены; пара сравнительных скриншотов.</p>

## Шаг 6: пишем обоснование выбора платформы (15 мин)

<p>По структуре Темы 3 напишите обоснование на 1 страницу (justification.md или PDF): задача → кандидаты (Sentinel-2 / коммерческий спутник / БПЛА) по осям разрешения-периодичности-покрытия → проверка фактов (ваша сцена: дата, облачность; ваш расчёт миссии: время, число линий) → решение (для легенд A/B — БПЛА для детализации + Sentinel-2 для регулярного скрининга) → ограничения и точки пересмотра. Не забудьте пункт правового чека (учёт аппарата, зоны — по актуальным официальным источникам; в учебном задании — как пункт плана, без выполнения).</p>

<p><em>Ожидаемый результат</em>: одностраничное обоснование со ссылками на ваши собственные числа из шагов 3 и 5.</p>

## Шаг 7: проектируем сеть почвенного опробования участка (20 мин)

<p>Дистанционная ветвь системы данных спроектирована в шагах 1–6. Теперь спроектируйте наземную ветвь на том же участке.</p>

<p>Выделите на участке элементарные зоны: наложите слой уклонов (из ЦМР), слой земного покрова и — при наличии — многолетний композит NDVI за 3–5 лет. Обоснуйте выбранное число зон.</p>

<p>Выберите схему опробования (регулярная сетка, зональная, по зонам продуктивности) и обоснуйте выбор через неоднородность участка и бюджет обследования.</p>

<p>Разместите точки отбора в отдельном слое otbor с полями id, zona, glubina, data_plan, metodika, sk (система координат).</p>

<p>Оформите техническое задание на агрохимическое обследование: перечень показателей (гумус, pH, доступные N, P, K, запас продуктивной влаги), глубина, сроки в фенологической привязке, требования к геопривязке точек, требования к формату сдачи результатов (CSV/GeoPackage с метаданными, не PDF).</p>

<p>Укажите, какие числовые параметры (шаг сетки, число уколов, глубина) вы взяли из источника — и приведите источник; какие оставили как параметр к уточнению.</p>

<p><em>Ожидаемый результа</em>т: слой otbor в GeoPackage и техническое задание на обследование (1 страница), в котором для каждой пробы обеспечены все пять обязательных атрибутов.</p>

## Шаг 8: проектируем трёхлетний ряд наблюдений (15 мин)

<p>Составьте календарный план трёх циклов обследования (2026, 2027, 2028) с разной периодичностью для показателей разной инерции: гумус и pH — раз в цикл ротации, доступные NPK — ежегодно, запас продуктивной влаги — дважды за сезон.</p>

<p>Для каждого цикла укажите пять условий сопоставимости и способ их контроля.</p>

<p>Опишите процедуру действий при вынужденной смене лаборатории (межлабораторное сличение) и при пропуске цикла.</p>

<p><em>Ожидаемый результат</em>: таблица «показатель × год × срок» и раздел «Обеспечение сопоставимости ряда» (0,5 страницы) в пояснительной записке.</p>

<p>Дополнение к продукту задания (редакция 2)</p>

<p>Помимо файлов, перечисленных выше, каталог a1-practicum/ включает:</p>

<p class="upgraded-list-item">Слой otbor (точки почвенного опробования с пятью обязательными атрибутами) в GeoPackage;</p>

<p class="upgraded-list-item">Техническое задание на агрохимическое обследование участка;</p>

<p class="upgraded-list-item">Календарный план трёхлетнего ряда наблюдений с разделом «Обеспечение сопоставимости».</p>

<p><em>Самопроверка по новым частям:</em> (1) у каждой точки отбора заполнены координаты с указанием системы координат, глубина, планируемая дата и методика; (2) схема опробования обоснована неоднородностью участка, а не выбрана по умолчанию; (3) все нормативные числовые параметры либо снабжены ссылкой на источник, либо явно помечены как параметр к уточнению; (4) формат сдачи результатов машиночитаемый; (5) план трёхлетнего ряда содержит процедуру на случай смены лаборатории.</p>

<p><strong>Продукт задания</strong><strong>. </strong>По итогам практикума у вас должен быть каталог a1-practicum/ (структура — по стандартам Урока 4):</p>

<p class="upgraded-list-item">plot.gpkg — контур модельного участка (100–200 га, корректная СК);</p>

<p class="upgraded-list-item">mission.gpkg + mission-map.pdf — схема маршрутов и оформленная карта;</p>

<p class="upgraded-list-item">таблица параметров миссии (из редактора Python или parameters.csv);</p>

<p class="upgraded-list-item">фрагмент Sentinel-2 (GeoTIFF) + метаданные сцены (дата, ID, облачность);</p>

<p class="upgraded-list-item">justification.md — обоснование выбора платформы (1 стр.);</p>

<p class="upgraded-list-item">README.md — паспорт мини-датасета: автор, дата, СК (EPSG), источники, инструменты.</p>

<p><strong>Самопроверка:</strong> (1) высота из вашей таблицы, подставленная в формулу GSD, возвращает ваш целевой GSD; (2) N × spacing ≥ ширина участка; (3) все слои проекта — в одной СК, и слой миссии лежит поверх участка без сдвига; (4) в обосновании каждое число прослеживается к шагу 3 или 5; (5) README заполнен по чек-листу Урока 4, раздел 2.</p>

<p><strong>Применить к своему хозяйству</strong><strong>. </strong>Проект на ВАШЕЙ земле. Замените модельный участок на реальное поле вашего хозяйства (или хозяйства-партнёра): оцифруйте его контур по OSM/Sentinel-2, повторите шаги 2–6 под реальную проблему этого поля — и вы получите готовое техническое задание для оператора БПЛА или для собственного полёта. Именно так этот практикум используется в профессиональных модулях П1 и П7. Перед реальным полётом обязателен правовой чек по действующим НПА РК.</p>

<p><strong>Дополнительные задания</strong> (по желанию). Чувствительность бюджета: повторите шаг 3 для GSD 1 см и 5 см; постройте график «GSD → время миссии» и найдите порог, за которым нужен второй аккумулятор (25 мин полезного времени).</p>

<p>Фактическая периодичность: через каталог CDSE посчитайте, сколько малооблачных сцен Sentinel-2 было над вашим участком за июнь–август прошлого сезона (упражнение Урока 3), и добавьте результат в обоснование.</p>

<p>Обработка без дрона: скачайте открытый демонстрационный набор снимков OpenDroneMap (github.com/OpenDroneMap/ODMdata) и соберите из него ортофотоплан в WebODM — полный цикл Урока 1, раздел 4, на реальных аэрофотоснимках.</p>
