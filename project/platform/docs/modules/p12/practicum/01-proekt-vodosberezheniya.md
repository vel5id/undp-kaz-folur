# Практикум: проект системы водосбережения для модельного участка

> Модуль **П12: Водосбережение и ирригация**. ⏱ **Трудозатраты:** 60–90 мин.
> Инструменты: браузер (NASA POWER, браузер Copernicus, OpenStreetMap), QGIS (бесплатно) — или любой редактор карт; табличный редактор (LibreOffice Calc / Google Sheets); опционально FAO CROPWAT + CLIMWAT (бесплатно).
> Данные: только открытые — NASA POWER, Sentinel-2 (Copernicus Data Space Ecosystem), OpenStreetMap, data.egov.kz.

## Цель практикума

**[Bloom: применять]** Собрать проект системы водосбережения для модельного участка в Акмолинской области: схема участка и источника воды, помесячный водный бюджет на реальных климатических данных, технологическое решение со схемой датчиков и экономическая часть с планом проверки цен и мер поддержки.

Практикум собирает воедино все три урока модуля: [водный бюджет](../lectures/01-vodnyj-byudzhet-uchastka.md), [выбор технологии](../lectures/02-kapelnoe-oroshenie-i-datchiki.md) и [экономику с каркасом проекта](../lectures/03-ekonomika-i-proekt-vodosberezheniya.md). Модельный сценарий продолжает региональный кейс Урока 1: картофельный клин у пруда в Акмолинской области.

## Что нужно подготовить

- [ ] **QGIS** (qgis.org, свободная лицензия) — установлен; либо используйте лёгкую альтернативу: инструмент рисования в браузере Copernicus. Базовые навыки QGIS — модуль [П2](../../p2/index.md).
- [ ] Доступ к **NASA POWER Data Access Viewer**: <https://power.larc.nasa.gov/data-access-viewer/> — без регистрации.
- [ ] Доступ к **браузеру Copernicus**: <https://dataspace.copernicus.eu/> (бесплатная регистрация).
- [ ] Табличный редактор (LibreOffice Calc, Google Sheets — любой).
- [ ] Шаблон проектного документа: структура из [Урока 3, §4](../lectures/03-ekonomika-i-proekt-vodosberezheniya.md) — шесть разделов.
- [ ] Опционально: **FAO CROPWAT 8.0 + CLIMWAT 2.0** (<https://www.fao.org/land-water/databases-and-software/cropwat/en/>, бесплатно, Windows; под Linux работает через Wine) — для расчёта ETc. Без CROPWAT задание выполняется в таблице по упрощённой схеме (шаг 3).

## Задание

### Шаг 1: выбираем модельный участок и рисуем схему (15 мин)

1. Откройте OpenStreetMap и найдите сельскую местность в Акмолинской области с прудом или малым водохранилищем рядом с полями (гидрография в OSM — синие полигоны). Подойдёт любой типичный участок — практикум учебный, привязка к конкретному хозяйству не требуется.
2. В QGIS: подключите подложку OSM (`Browser → XYZ Tiles → OpenStreetMap`), создайте GeoPackage-слой `uchastok` (полигоны) и нарисуйте: контур модельного участка (несколько десятков гектаров рядом с водоёмом) и контур источника воды. Добавьте линейный слой `podacha` — трассу подачи воды от источника к участку.
3. Разделите участок на 2–4 поливных блока (полигоны в том же слое, поле-атрибут `blok`), добавьте точечный слой `datchiki` — по 1–2 точки мониторинга влажности на блок ([Урок 2, §3.3](../lectures/02-kapelnoe-oroshenie-i-datchiki.md)).
4. Экспортируйте схему: `Проект → Импорт/Экспорт → Экспортировать карту в изображение` → `shema-uchastka.png`.

**Ожидаемый результат:** файл `proekt-p12.gpkg` со слоями `uchastok`, `podacha`, `datchiki` + картинка `shema-uchastka.png`, на которой видны участок, блоки, источник, трасса и точки датчиков.

!!! warning "Правовой режим данных"
    В публичную версию схемы и документа не выносите точные координаты — области и района достаточно ([Урок 3, §4](../lectures/03-ekonomika-i-proekt-vodosberezheniya.md)). Если для оценки объёма источника используете учебную батиметрию платформы — только уровни A/B: обезличенный датасет `datasets/bathymetry-training-80k.csv` («водохранилище степной зоны Казахстана», локальная СК, без геопривязки) и сетка `modules/a4/data/bathymetry-grid-100m.tif`. Политика — [Датасеты платформы](../../../datasets.md).

### Шаг 2: скачиваем климатические данные NASA POWER (10 мин)

1. Откройте Data Access Viewer: <https://power.larc.nasa.gov/data-access-viewer/>.
2. Выберите сообщество **Agroclimatology**, временное разрешение **Monthly & Annual**, кликните точку в центре вашего модельного участка.
3. Отметьте параметры: осадки (Precipitation), температура воздуха на 2 м (Temperature at 2 Meters). Задайте период не короче последних 20 полных лет. Скачайте CSV.
4. Откройте CSV в табличном редакторе и постройте **климатическую норму**: среднемноголетние осадки и температуру по каждому месяцу.

**Ожидаемый результат:** таблица `voda-byudzhet.ods/xlsx`, лист «Климат»: 12 строк-месяцев, колонки «осадки, мм (норма)» и «температура, °C (норма)», плюс строка-источник: «NASA POWER, точка [область/район], период [годы], дата выгрузки».

### Шаг 3: считаем водный бюджет (20–25 мин)

**Вариант А (рекомендуемый): CROPWAT.** Загрузите климат ближайшей станции из CLIMWAT (или введите нормали из шага 2 вручную), выберите культуру «Potato» из стандартной базы (значения Kc по фазам — из таблиц FAO-56, встроены в программу), задайте даты посадки, типичные для региона. Программа вернёт помесячные ETo, ETc, эффективные осадки (укажите метод, например USDA S.C.) и потребность в орошении.

**Вариант Б (таблица, без установки ПО).** На листе «Бюджет»: для каждого месяца вегетации выпишите ETo по ближайшей станции из CLIMWAT (либо используйте связку «нормали шага 2 + ноутбук Colab модуля»: `<URL будет назначен при создании репозитория ноутбуков>`); Kc по фазам картофеля возьмите из таблиц FAO-56 (<https://www.fao.org/4/x0490e/x0490e00.htm>) — с указанием таблицы-источника; посчитайте `ETc = Kc × ETo` и `дефицит = ETc − эффективные осадки` (для черновика допустимо консервативно принять эффективными не более ~70–80% осадков — зафиксируйте принятую долю как допущение в документе).

Итоги на листе «Бюджет»:

- помесячный дефицит и **оросительная норма** (сумма за сезон, переведите мм → м³/га: 1 мм = 10 м³/га);
- **поливная норма** по формуле [Урока 1, §3](../lectures/01-vodnyj-byudzhet-uchastka.md) — значения ППВ и влажности перед поливом задайте сценарно, пометив «оценка, уточнить полевым измерением»;
- **сценарий засушливого года**: пересчитайте дефицит по годам из ряда NASA POWER с минимальными летними осадками (возьмите фактический худший год из вашей выгрузки, а не выдуманный коэффициент).

**Ожидаемый результат:** заполненный лист «Бюджет»: у каждой цифры — источник (NASA POWER / CLIMWAT / FAO-56 / «оценка»); внизу — оросительная норма в м³/га для среднего и засушливого года.

### Шаг 4: проверяем источник по снимкам Sentinel-2 (10 мин)

1. В браузере Copernicus найдите свой водоём. Откройте два безоблачных снимка Sentinel-2: конец апреля–май (после наполнения талыми водами) и август того же года.
2. Визуально сравните площадь зеркала (в браузере есть инструмент измерения площади — обведите зеркало на обоих снимках).
3. Запишите в документ: во сколько раз (примерно) сокращается зеркало к пику потребности культуры, и вывод — можно ли записывать весенний объём в приход целиком.

**Ожидаемый результат:** два скриншота (весна/август) с измеренной площадью зеркала + 2–3 предложения вывода в разделе «Паспорт участка».

### Шаг 5: технологическое решение (10 мин)

По решающему дереву [Урока 2, §1.1](../lectures/02-kapelnoe-oroshenie-i-datchiki.md) обоснуйте выбор технологии для картофеля (2–3 предложения), перечислите узлы системы ([Урок 2, §2](../lectures/02-kapelnoe-oroshenie-i-datchiki.md)) с пометкой, какие требования к каждому узлу диктует ваш источник (открытый водоём → двухступенчатая фильтрация), и опишите правило назначения полива по датчикам из вашей схемы шага 1 (пороги — «задать по справочным данным культуры, источник указать»).

**Ожидаемый результат:** раздел «Технологическое решение» проектного документа (0,5–1 страница).

### Шаг 6: экономическая часть и сборка документа (15–20 мин)

1. Перенесите в документ структуру затрат из [Урока 3, §1](../lectures/03-ekonomika-i-proekt-vodosberezheniya.md) — таблицей «статья → как получаем цену (КП №1, КП №2, смета) → статус». Цены не выдумывайте: у учебного проекта все статусы — «запросить КП».
2. Опишите базовую линию: что и чем измеряем до внедрения (счётчик воды, записи урожая по блокам).
3. Раздел «Господдержка»: таблица «мера → где проверяем (adilet.zan.kz / gov.kz) → статус: не проверено». Проверка реальных программ — за рамками практикума, в проект попадает только план проверки ([Урок 3, §3](../lectures/03-ekonomika-i-proekt-vodosberezheniya.md)).
4. Раздел «Риски и план первого сезона»: минимум четыре риска с мерами ([Урок 3, §4](../lectures/03-ekonomika-i-proekt-vodosberezheniya.md), [Урок 2, §4](../lectures/02-kapelnoe-oroshenie-i-datchiki.md)).
5. Соберите документ `proekt-vodosberezheniya.pdf`: шесть разделов по каркасу [Урока 3, §4](../lectures/03-ekonomika-i-proekt-vodosberezheniya.md) + схема из шага 1 + таблицы шагов 2–3 + скриншоты шага 4.

**Ожидаемый результат:** готовый PDF-документ проекта (3–6 страниц) со всеми шестью разделами.

## Продукт задания

По итогам практикума у вас должны быть:

- [ ] `proekt-p12.gpkg` — слои участка, блоков, трассы и датчиков;
- [ ] `shema-uchastka.png` — схема участка;
- [ ] `voda-byudzhet.ods/xlsx` — листы «Климат» и «Бюджет» с источником каждой цифры;
- [ ] `proekt-vodosberezheniya.pdf` — проектный документ из шести разделов.

**Самопроверка:** (1) в таблице бюджета нет ни одной цифры без источника или пометки «оценка»; (2) оросительная норма посчитана для среднего И засушливого года; (3) в экономической части нет ни одной цены и ни одной суммы субсидии — только статьи и план их проверки; (4) пик дефицита в вашем бюджете приходится на летние месяцы (если нет — проверьте Kc по фазам и единицы измерения).

!!! note "Применить к своему хозяйству"
    **Проект на ВАШЕЙ земле.** Повторите шаги 1–6 для реального участка вашего хозяйства: свой контур, свой источник, своя культура, фактическая точка NASA POWER. Добавьте то, чего нет в учебном сценарии: реальный правовой статус водопользования (проверка по adilet.zan.kz с датой), заказ анализа воды, запрос двух-трёх КП. Полученный документ — рабочая основа для разговора с поставщиком и для заявки на поддержку через модуль [П14](../../p14/index.md). Точные координаты и внутренние данные хозяйства в публичную версию не включайте.

## Дополнительные задания (по желанию)

1. Постройте бюджет для второй культуры (морковь или капуста — база CROPWAT) и сравните оросительные нормы: как меняется нагрузка на источник при разной структуре посевов?
2. Повторите шаг 4 для трёх разных лет из архива Sentinel-2: устойчиво ли поведение водоёма или год на год не приходится?
3. Если ваш источник — пруд: пройдите модуль [П11](../../p11/index.md) и постройте кривую «уровень–объём» на учебном батиметрическом датасете платформы (уровень A) — она превратит «зеркало усохло вдвое» в кубометры.
