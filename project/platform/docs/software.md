## Встроенный редактор Python {#python}

**Зачем.** Запускать учебные расчёты прямо в уроке: таблицы, графики, карты точек.

**Где взять.** Ничего скачивать не нужно. Редактор находится в каждом уроке на шаге **«Практика в Python»** (квадратик с этим названием в полосе шагов над заголовком урока). Все упражнения одним списком — на странице [Python-практика](python-practice.md).

![Редактор в уроке: кнопка «Запустить» под кодом, ниже — готовый запрос для нейросети](assets/img/software/editor-run.jpg){ .folur-shot loading=lazy }

*Редактор в уроке: кнопка «Запустить» под кодом, ниже — готовый запрос для нейросети.*

![Пример результата: таблицы под кодом и кнопки скачивания файлов](assets/img/software/editor-result.jpg){ .folur-shot loading=lazy }

*Пример результата: таблицы под кодом и кнопки скачивания файлов.*

![Вкладка «Мой участок»: координаты поля, контур и снимок подставляются здесь](assets/img/software/editor-own.jpg){ .folur-shot loading=lazy }

*Вкладка «Мой участок»: координаты поля, контур и снимок подставляются здесь.*

**Первый запуск.**

1. Откройте шаг «Практика в Python» и прочитайте задание над редактором.
2. Нажмите кнопку **▶ Запустить** под кодом. В первый раз загружается сам Python — подождите до минуты, пока в строке состояния не появится «Готово к запуску».
3. Результат — таблицы, графики, файлы для скачивания — появится ниже, в блоке «Результат».
4. Измените число в коде (например, порог) и запустите ещё раз. Кнопка «Восстановить пример» возвращает исходный код.

**Свои данные.** Каждое упражнение сразу работает на учебном наборе. Если упражнение умеет читать ваш файл, в блоке **«Свои данные и возможности среды»** есть строка с именем файла и кнопка **«Подставить свой файл»**: выберите файл на компьютере — переименовывать его не нужно. Кнопка «Вернуть учебные данные» отменяет замену. Файлы остаются в вашем браузере и никуда не отправляются.

**Свой участок.** Над редактором есть вкладка **«Мой участок»**. В ней можно вставить координаты своего поля (по точке в строке: широта, долгота) или загрузить его контур — GeoJSON, KML, GeoPackage либо Shapefile одним архивом `.zip` — и снимок в формате GeoTIFF. В ответ вы получите паспорт данных, площадь в гектарах, систему координат и оценку съёмки. Загруженное сохраняется в вашем браузере и остаётся доступным в следующих уроках.

**То же самое — через нейросеть.** Под кодом каждого упражнения есть готовый запрос для любой нейросети: в нём названы задача, данные и параметры. Фиолетовым и в коде, и в запросе выделено главное — что стоит менять и какие данные используются. Кнопка «Скопировать запрос» копирует его вместе с кодом. Ответ нейросети сверяйте с результатом редактора.

**Как понять, что получилось.** Под кодом появились таблица или график, а в строке состояния нет слова «ошибка».

**Чего редактор не умеет.** Он работает без доступа в интернет: не скачивает спутниковые снимки и не входит в Google Earth Engine. Такие задания в уроках помечены как расширенные и выполняются в [Google Colab](#colab) или [QGIS](#qgis).

## QGIS — настольная ГИС {#qgis}

**Зачем.** Собирать карты: границы полей, снимки, рельеф, расчёт площадей, оформление карты для печати.

**Где взять.** Официальная страница загрузки — <https://qgis.org/download/>. Выбирайте версию с пометкой **LTR** (Long Term Release, версия долгосрочной поддержки) — она стабильнее.

![Страница загрузки QGIS: нужная кнопка — «Download LTR»](assets/img/software/qgis-download.jpg){ .folur-shot loading=lazy }

*Страница загрузки QGIS: нужная кнопка — «Download LTR». Нужное место обведено фиолетовым.*

**Установка (Windows).**

1. Сайт сначала предложит пожертвование — оно необязательно: нажмите «Skip it and go to download». Затем скачайте установщик LTR-версии кнопкой «Download LTR» (файл `.msi`, около 1 ГБ).
2. Запустите скачанный файл и нажимайте «Next» / «Далее», ничего не меняя. Установка занимает 5–10 минут.
3. В меню «Пуск» появится папка QGIS. Запускайте ярлык **QGIS Desktop** (не «QGIS Server» и не «OSGeo4W Shell»).

Для macOS и Linux на той же странице есть свои инструкции.

**Русский интерфейс.** Если меню на английском: «Settings → Options… → General» → поставьте галочку «Override System Locale» → выберите язык «Русский» → перезапустите QGIS. В русском интерфейсе этот путь называется «Настройки → Параметры… → Общие → Переопределить системную локаль».

**Первые шаги.**

1. **Создайте и сохраните проект:** «Проект → Сохранить как…», выберите папку и имя, например `ferma.qgz`. Сохраняйте после каждого шага (Ctrl+S).
2. **Добавьте карту-подложку.** В левой панели «Браузер» раскройте «XYZ Тайлы» (в части версий раздел подписан «Тайлы XYZ») и дважды щёлкните «OpenStreetMap» — в окне появится карта мира.
3. **Установите модуль (плагин), когда его просит урок:** «Модули → Управление модулями…» → вкладка «Все» → в строке поиска наберите название (например, `QuickMapServices` или `QuickOSM`) → кнопка «Установить модуль».
4. **Откройте свой файл:** «Слой → Добавить слой → Добавить векторный слой…» (границы, точки) или «Добавить растровый слой…» (снимок, рельеф). Проще — перетащить файл мышью в окно карты.

### QGIS по шагам в картинках {#qgis-steps}

Шесть действий, которые встречаются почти в каждом практикуме с картой. Снимки сделаны в QGIS 3.44 с русским интерфейсом на учебном контуре с условными координатами; нужные места обведены фиолетовым.

**Шаг 1. Подложка OpenStreetMap.** В панели «Браузер» (слева вверху) раскройте раздел «XYZ Тайлы» и дважды щёлкните «OpenStreetMap». Слой появится ниже, в панели «Слои».

![QGIS: панель «Браузер», раздел «XYZ Тайлы», ниже — панель «Слои» с подложкой OpenStreetMap](assets/img/software/qgis-step1-osm.png){ .folur-shot loading=lazy }

*QGIS: панель «Браузер», раздел «XYZ Тайлы», ниже — панель «Слои» с подложкой OpenStreetMap.*

**Шаг 2. Спутниковая подложка — чтобы видеть само поле.** На карте OpenStreetMap в степи часто почти пусто: нарисованы дороги и посёлки, а полей нет. Добавьте поверх спутниковую мозаику:

1. Откройте «Слой → Источники данных» (или Ctrl+L) и слева выберите раздел **XYZ**.
2. В поле **URL** вставьте адрес спутниковой мозаики Esri World Imagery:

    ```text
    https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}
    ```

3. Нажмите **«Добавить»**, затем «Закрыть». Чтобы подложка осталась в «Браузере» насовсем, нажмите «Создать» и дайте ей имя.

![Окно «Источники данных», раздел XYZ: адрес подложки в поле URL и кнопка «Добавить»](assets/img/software/qgis-step2-sources.png){ .folur-shot loading=lazy }

*Окно «Источники данных», раздел XYZ: адрес подложки в поле URL и кнопка «Добавить».*

![Спутниковая подложка в окне карты: видны поля, колки и дороги; в панели «Слои» — два слоя, OpenStreetMap выключен галочкой](assets/img/software/qgis-step3-satellite.jpg){ .folur-shot loading=lazy }

*Спутниковая подложка в окне карты: видны поля, колки и дороги; в панели «Слои» — два слоя, OpenStreetMap выключен галочкой.*

!!! warning "Что помнить о спутниковой подложке"
    Это мозаика из снимков разных лет: дата съёмки неизвестна и меняется от места к месту. Она годится, чтобы **найти поле и обвести его**, но не для оценки состояния посевов — для этого берите снимок Sentinel-2 с известной датой в [Copernicus Browser](#copernicus). Подложка принадлежит компании Esri; условия использования — на её сайте.

**Шаг 3. Новый слой для своих полей.** «Слой → Создать слой → Создать слой GeoPackage…». Укажите файл, **имя таблицы** и **тип геометрии «Полигон»**; систему координат выберите в строке под типом геометрии. Ниже добавляются колонки (например, `name`).

![Окно «Создать слой GeoPackage»: имя таблицы и тип геометрии «Полигон»](assets/img/software/qgis-step4-new-layer.png){ .folur-shot loading=lazy }

*Окно «Создать слой GeoPackage»: имя таблицы и тип геометрии «Полигон».*

**Шаг 4. Система координат проекта.** «Проект → Свойства…» → слева раздел **«Система координат»**. Быстрее — щёлкнуть по кнопке с кодом EPSG в правом нижнем углу окна. В строке «Поиск» наберите код зоны UTM своего района (для Северного Казахстана — 32641, 32642 или 32643), выберите строку в списке и нажмите «OK».

![Окно «Свойства проекта», раздел «Система координат»](assets/img/software/qgis-step5-props.png){ .folur-shot loading=lazy }

*Окно «Свойства проекта», раздел «Система координат».*

![Поиск системы координат по коду: 32642 — WGS 84 / UTM zone 42N, единицы — метры](assets/img/software/qgis-step5-crs.png){ .folur-shot loading=lazy }

*Поиск системы координат по коду: 32642 — WGS 84 / UTM zone 42N, единицы — метры.*

**Шаг 5. Обвести поле.** Выделите свой слой в панели «Слои», нажмите карандаш **«Режим редактирования»**, затем кнопку **«Добавить полигональный объект»** и щёлкайте по углам поля; правая кнопка мыши завершает контур. Сохраните правки кнопкой с дискетой рядом с карандашом.

![Оцифровка по спутниковой подложке: карандаш «Режим редактирования», кнопка «Добавить полигональный объект», внизу справа — система координат проекта EPSG:32642](assets/img/software/qgis-step6-edit.jpg){ .folur-shot loading=lazy }

*Оцифровка по спутниковой подложке: карандаш «Режим редактирования», кнопка «Добавить полигональный объект», внизу справа — система координат проекта EPSG:32642.*

**Шаг 6. Площадь в гектарах.** Правой кнопкой по слою → «Открыть таблицу атрибутов» → кнопка «Калькулятор полей». Имя поля — `area_ha`, тип — десятичное число, выражение — `$area / 10000`. Под выражением сразу виден результат («Просмотр»).

![Калькулятор полей: новое поле area_ha и выражение $area / 10000; в строке «Просмотр» — 121,26 га](assets/img/software/qgis-step7-calculator.png){ .folur-shot loading=lazy }

*Калькулятор полей: новое поле area_ha и выражение $area / 10000; в строке «Просмотр» — 121,26 га.*

!!! danger "Ловушка, в которую мы попали сами"
    Для учебного контура QGIS сначала показал **201,99 га** вместо **121,26 га**. Причина: слой хранился в градусах (EPSG:4326), и площадь посчиталась так, будто градус долготы на широте 53° равен градусу на экваторе. После сохранения слоя в метрической проекции (шаг 7) то же выражение дало 121,26 га — столько же получилось в независимом расчёте на Python и у [нейросети](#opencode-example). Вывод: **площадь считайте только для слоя в метрической проекции** и сверяйте число вторым способом.

**Шаг 7. Сохранить слой в метрической проекции.** Правой кнопкой по слою → «Экспорт → Сохранить объекты как…». Формат — GeoPackage, в строке **«Система координат»** выберите зону UTM, укажите имя файла и нажмите «OK».

![Окно сохранения слоя: формат GeoPackage и система координат EPSG:32642 — WGS 84 / UTM zone 42N](assets/img/software/qgis-step8-export.png){ .folur-shot loading=lazy }

*Окно сохранения слоя: формат GeoPackage и система координат EPSG:32642 — WGS 84 / UTM zone 42N.*

**Что где находится.**

| Что нужно сделать | Где это в QGIS (русский интерфейс) |
|---|---|
| Создать свой слой для оцифровки полей | «Слой → Создать слой → Создать слой GeoPackage…» |
| Включить рисование | выделите слой в панели «Слои» → кнопка с карандашом «Режим редактирования» |

| Чтобы соседние поля не перекрывались | панель «Инструменты прилипания» → «Вырезать наложения» |
| Посмотреть таблицу слоя | правой кнопкой по слою → «Открыть таблицу атрибутов» |
| Посчитать площадь | в таблице атрибутов → «Калькулятор полей», выражение `$area / 10000` даёт гектары |
| Задать систему координат проекта | «Проект → Свойства…» → «Система координат» |
| Сохранить слой в другой файл или проекцию | правой кнопкой по слою → «Экспорт → Сохранить объекты как…» |
| Раскрасить слой по значениям колонки | правой кнопкой по слою → «Свойства…» → «Стиль» → в списке вверху «Символизация по уникальным значениям» |
| Посчитать уклоны по рельефу | «Растр → Анализ → Уклон…» |
| Построить буфер вокруг объекта | «Вектор → Геообработка → Буфер…» |
| Обрезать снимок по границе | «Растр → Извлечение → Обрезать растр по маске…» |
| Добавить таблицу CSV с координатами | «Слой → Добавить слой → Добавить слой из текста с разделителями…» |
| Найти любой инструмент по названию | меню «Анализ» → «Панель инструментов» и строка поиска |
| Оформить карту для печати | «Проект → Создать макет…» |
| Сохранить вид карты картинкой | «Проект → Импорт/экспорт → Экспорт в изображение…» |

**Частая ошибка.** Площадь получается вида `0,0002`: слой хранится в градусах (EPSG:4326). Сохраните его в метрической проекции зоны UTM вашего района («Экспорт → Сохранить объекты как…», для Северного Казахстана — EPSG:32641, EPSG:32642 или EPSG:32643, по долготе района) и посчитайте заново.

**Как понять, что получилось.** В окне карты видна подложка, в панели «Слои» слева есть ваш слой, проект открывается заново после закрытия программы.

!!! note "О названиях пунктов меню"
    Названия на этой странице и в уроках сверены 8 октября 2026 года с файлами русского перевода QGIS трёх версий — 3.40, 3.44 (сейчас её предлагают как LTR) и 4.2, а снимки сделаны в QGIS 3.44. Панели «Браузер» и «Слои» во всех трёх версиях называются одинаково. Что стоит знать:

    - меню с инструментами анализа (в английском интерфейсе — Processing) по-русски называется **«Анализ»**, а не «Обработка»; общий каталог инструментов — «Анализ → Панель инструментов»;
    - раздел подложек в «Браузере» подписан «XYZ Тайлы» либо «Тайлы XYZ» — зависит от версии;
    - инструмент «Массив смещённых (параллельных) линий» в версии 3.40 называется «Массив параллельных линий»;
    - в версии 4.2 часть новых строк ещё не переведена и показывается по-английски.

    Если пункт у вас называется иначе — ищите его по смыслу через «Анализ → Панель инструментов».

Справка на русском: <https://docs.qgis.org/latest/ru/docs/user_manual/>.

## Copernicus Browser — спутниковые снимки в браузере {#copernicus}

**Зачем.** Смотреть и скачивать бесплатные снимки Sentinel-2 по своему полю: обычное цветное изображение и готовые индексы, например NDVI.

**Где взять.** Откройте <https://browser.dataspace.copernicus.eu/> — устанавливать ничего не нужно.

![Первое окно Copernicus Browser: «Use anonymously» — смотреть без регистрации](assets/img/software/copernicus-start.jpg){ .folur-shot loading=lazy }

*Первое окно Copernicus Browser: «Use anonymously» — смотреть без регистрации. Нужное место обведено фиолетовым.*

| | Sentinel-2 (готовый снимок) | Съёмка дроном + WebODM |

## OpenCode — ИИ-агент, который пишет и запускает код {#opencode}

**Зачем.** В ИИ-заданиях академических модулей (А1–А6) нейросети поручают написать и проверить скрипт. OpenCode — открытый (open source) агент для такой работы: он читает файлы в выбранной папке, предлагает план, пишет код и запускает его. Работает как приложение, в терминале и как расширение редактора кода. Заменяем любым аналогом, а все задания курса выполнимы и без ИИ.

**Где взять.** Официальная страница загрузки — <https://opencode.ai/download>.

![Страница загрузки OpenCode: приложение для Windows](assets/img/software/opencode-download.jpg){ .folur-shot loading=lazy }

*Страница загрузки OpenCode. Нужное место обведено фиолетовым.*

**Установка.**

1. **Проще всего — приложение.** В разделе «OpenCode Desktop» в строке «Windows (x64)» нажмите «Download», запустите скачанный файл. Для macOS и Linux — соседние строки.
2. **Вариант для терминала.** Команды установки приведены на той же странице и в документации <https://opencode.ai/docs/>. Они меняются от версии к версии, поэтому копируйте их с сайта, а не из старых инструкций.

![Раздел Install в документации OpenCode](assets/img/software/opencode-install.jpg){ .folur-shot loading=lazy }

*Раздел «Install» в документации OpenCode: команды установки для терминала.*

**Подключение модели.** Сам OpenCode бесплатен, но ему нужна нейросеть-«двигатель». Команда `/connect` открывает список поставщиков моделей: выберите поставщика и вставьте свой ключ доступа (API key). Работа модели оплачивается у её поставщика по его тарифу — до начала проверьте стоимость и установите лимит расходов в кабинете поставщика.

**Первые шаги.**

1. Создайте **отдельную пустую папку** под задание и положите в неё только учебные файлы (например, контур поля `field.geojson`).
2. Откройте эту папку в OpenCode: в приложении — выбором папки, в терминале — перейдите в папку и наберите `opencode`.
3. Напишите задачу в поле внизу окна: какой файл взять, что посчитать, в каких единицах и куда сохранить результат.
4. Под полем ввода переключите режим с **Build** на **Plan** (в терминале — клавиша Tab). В режиме Plan агент только предлагает план и ничего не меняет.
5. Прочитайте план. Если он верен — переключитесь на Build и попросите выполнить.

![Окно OpenCode: запрос на расчёт площади поля и строка режима под ним](assets/img/software/opencode-prompt.png){ .folur-shot loading=lazy }

*Окно OpenCode: запрос набран, под ним — режим (Build), выбранная модель и кнопка отправки.*

![Окно OpenCode: переключатель режимов Build и Plan](assets/img/software/opencode-mode.png){ .folur-shot loading=lazy }

### Пример: нейросеть считает и рисует карту {#opencode-example}

Тот же учебный контур, что на снимках QGIS выше. В папке лежит один файл `field.geojson`; агенту отправлен такой запрос (**главное выделено**):

> В папке лежит **field.geojson** — контур учебного поля (координаты условные, WGS 84). Напиши скрипт field_map.py на Python (geopandas, matplotlib) и запусти его: 1) определи **зону UTM** по центру поля и переведи контур в метры; 2) посчитай **площадь в гектарах и периметр в километрах**, сохрани в passport.csv; 3) построй линии маршрутов съёмки дроном внутри поля **с шагом 36 м** вдоль длинной стороны, посчитай число маршрутов и их суммарную длину; 4) сохрани визуализацию **map.png**: контур поля, линии маршрутов, подпись с площадью, оси в метрах, заголовок на русском. **Не выдумывай данные**: используй только field.geojson и шаг 36 м. Если чего-то не хватает — напиши об этом, а не подставляй. В конце коротко перечисли полученные числа и **как их проверить вручную**.

Агент сам написал скрипт, запустил его, наткнулся на ошибку кодировки, исправил её и примерно через минуту вернул таблицу и картинку:

![Карта, которую построила нейросеть: контур поля, 28 маршрутов съёмки с шагом 36 м, подпись площади](assets/img/software/opencode-result-map.png){ .folur-shot loading=lazy }

*Карта, которую построила нейросеть: контур поля, 28 маршрутов съёмки с шагом 36 м, подпись площади.*

| Что получилось | У нейросети | Проверка |
|---|---|---|
| Зона UTM | 42N, EPSG:32642 | совпадает: долгота центра ≈ 66° |
| Площадь | 121,258 га | QGIS, калькулятор полей в метрической проекции: 121,258 га; независимый расчёт на Python: 121,258 га |
| Периметр | 4,424 км | независимый расчёт на Python: 4,424 км |
| Маршрутов с шагом 36 м | 28 | прикидка: ширина поля 1003,6 м ÷ 36 м ≈ 27,9 |
| Суммарная длина маршрутов | 33,8 км | прикидка: 28 × 1208 м ≈ 33,8 км |

**Чему учит пример.**

- Нейросеть дала не только числа, но и **картинку** — по ней сразу видно, туда ли легли маршруты.
- Она сама оговорила допущение: линии проложены параллельно длинной стороне. Это пришлось бы уточнять и у человека.
- Проверка заняла минуту и нашла ошибку — но **не у нейросети, а в первом расчёте QGIS** (201,99 га из-за слоя в градусах, см. [шаг 6](#qgis-steps)). Сверка двумя способами ловит ошибки с обеих сторон.

Пример выполнен 8 октября 2026 года в OpenCode 1.17.9 с моделью DeepSeek Flash. Другие агенты — Codex, Claude Code — принимают такой же запрос; результат у другой модели может отличаться, поэтому проверка обязательна.

**Рекомендации для заданий курса.**

| Что делать | Зачем |
|---|---|
| Начинать с режима **Plan**, в Build переходить после проверки плана | вы видите, что агент собирается делать, до того как он изменит файлы |
| Называть в запросе **файл, нужный результат, единицы и систему координат** | это те же места, что выделены фиолетовым в запросах [встроенного редактора](#python); без них агент додумывает сам |
| Добавлять фразу «**Не выдумывай данные: если чего-то не хватает — спроси**» | агент иначе подставит правдоподобные, но несуществующие числа |
| Работать в **отдельной папке** с учебными файлами | агент читает и меняет всё, что лежит в открытой папке |
| Не класть в папку персональные данные, договоры и точные координаты чужих участков | содержимое файлов отправляется поставщику модели |
| **Сверять числа**: площадь — с QGIS или вкладкой «Мой участок», расчёты — со встроенным редактором | агент ошибается уверенно; в курсе засчитывается проверенный результат |
| Просить сохранить скрипт и объяснить каждую строку | результат можно повторить без ИИ и показать преподавателю |
| Если агент испортил файлы — команда `/undo` (вернуть обратно — `/redo`) | отменяет последнее изменение |
| Не использовать `/share` с непубличными данными | команда создаёт ссылку на весь разговор |
| В начале работы над проектом выполнить `/init` | агент изучит папку и запишет правила проекта в файл `AGENTS.md` |

**Как понять, что получилось.** В папке появился скрипт и файл с результатом, скрипт запускается повторно без агента, а числа совпадают с вашей проверкой.

## Если что-то не получается

- **Редактор Python долго «думает».** Первый запуск загружает Python — подождите минуту. Если ничего не изменилось, обновите страницу и запустите ещё раз.
- **QGIS показывает пустую карту.** Правой кнопкой по слою → «Увеличить до слоя».
- **Площадь в QGIS получилась почти вдвое больше ожидаемой.** Слой хранится в градусах: сохраните его в зоне UTM ([шаг 7](#qgis-steps)) и посчитайте заново.
- **На подложке OpenStreetMap пусто, поля не видно.** Добавьте спутниковую подложку ([шаг 2](#qgis-steps)).
- **Слои «разъезжаются».** У них разные системы координат: проверьте систему координат каждого слоя в его свойствах.
- **Снимок не скачивается из Copernicus Browser.** Проверьте, что вы вошли в учётную запись.
- **В уроке названа программа, которой нет на этой странице.** Напишите преподавателю — добавим.
