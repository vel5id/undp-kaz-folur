Свои файлы и возможности среды

Загрузите CSV, JSON, GeoJSON, PNG, JPEG или GeoTIFF. В коде обращайтесь к файлу по его имени: pd.read_csv("данные.csv"), Image.open("снимок.png") или rasterio.open("растр.tif"). Файлы обрабатываются в изолированной памяти браузера, на сервер не отправляются. Сетевой доступ из Python отключён. До 20 МБ на файл, 50 МБ суммарно.

Свои файлы не выбраны.

Доступны NumPy, pandas, Matplotlib, Pillow, SciPy, scikit-learn, GeoPandas и rasterio. Earth Engine, GPU, QGIS и OpenDroneMap требуют отдельной среды. Здесь можно обработать их экспортированные данные. При первом запуске загружаются Python и библиотеки; следующие запуски используют кеш браузера.
