# Приложение к Этапу 1: Детальный бенчмарк 14 курсов-аналогов

> **Назначение.** Доказательная база под 30 лучших практик, применённых в архитектуре платформы FOLUR (см. основной документ `03_folur-practices-analysis.md`, раздел 2). Приложение к отчёту для ПРООН.
> **Исполнитель роли:** методолог + GIS/AI-эксперты. **Объект:** 14 онлайн-курсов пяти провайдеров, сопоставимых с задачей FOLUR (ГИС/ДЗЗ, агроэкология, устойчивое землепользование, цифровое агрообразование).
> **Метод и статус верификации:** каждый курс разобран по 20 полям (программа, длительность, стоимость, сертификация, оценивание, hands-on, инструменты, сильные/слабые стороны) с проверкой по первоисточникам. **Верифицировано 13 из 14**; 1 курс (ITC UAV) помечен `[UNVERIFIED]` — часть данных закрыта за логином. Машиночитаемая база: 14 JSON-карточек курсов + `catalog.json`.

## 2. Пофакторный разбор по провайдерам

### 2.1 Coursera (3 курса) — эталон структуры и прогрессии

**Geospatial Data Science.** Чистая спиральная прогрессия: основы → десктоп-ГИС → ДЗЗ → веб/облако → ML → data engineering, каждый курс переиспользует предыдущий. Полностью открытый $0-стек (Python/GeoPandas/QGIS/PostGIS/GEE). Outcome-названия уроков («Crunch Vectors with GeoPandas: Spatial Joins…»). **Слабости:** только английский; generic — ноль агро- и регионального контекста; облачные модули тянут платный AWS/GCP/Airflow.

**Geneva — Ecosystem Services.** Междисциплинарность «один метод — много линз» (технич./эконом./социально-полит.); **целый модуль о слабостях и предвзятостях метода** (научная честность); игра-симулятор TRADE-OFF как «хук» до теории; опциональный capstone на $0-стеке (QGIS+InVEST). 4.8/5 по 742 отзывам. **Слабости:** видео-центричность (длинные монотонные лекции — прямая претензия рецензентов); мало практики; политико-академическая рамка вместо МСБ.

**Florida — Sustainable Land Management.** Сквозной **проект «на ВАШЕЙ земле»**, сдаётся по частям (модули 2/4/6) — рецензенты хвалят «применил сразу к своей работе»; связка «водокачество → регуляция (TMDL) → BMP → почвы/питание/орошание»; переносимый инструмент — баланс питательных веществ. **Слабости:** флоридская специфика (влажные субтропики, US-регуляции) — для сухостепного СКО нерелевантна; «сухие» лекции; ноль ГИС/вычислений.

→ **Взято в FOLUR:** outcome-названия уроков, спиральная прогрессия датасета, capstone, «проект на своей земле», урок о границах метода, инструмент-на-модуль, привязка к нормам (с пометкой `[UNVERIFIED]` до сверки норм РК).

### 2.2 FAO eLearning Academy (4 курса) — эталон сертификации и доступности

Все 4 курса: **бесплатны вместе с сертифицирующим Open Badge**; порог **75%**; компактные (4–5 уроков, ~2–3,5 ч) — низкий отток; логичный каркас «концепция → принципы → внедрение → стимулы → мониторинг» (SLM); мультиязычность (один курс — до 4 языков) как доказанная модель локализации; офлайн-пакеты (~68–114 МБ) для слабого интернета; сценарные (не только тестовые) экзамены; привязка к авторитетным рамкам (10 Elements of Agroecology, VGSSM, WOCAT, ELD, ЦУР 15.3). **Общая слабость:** почти нет hands-on (концепции без полевых заданий/ГИС), аудитория — чиновники/тренеры, а не фермеры; ноль казахстанских кейсов.

→ **Взято в FOLUR:** порог 75% + Open Badges + verify-страница (реализовано QR-кодами); каркас модуля; офлайн-пакет + PDF-конспект; сценарные вопросы в экзамене; авторитетные цитируемые рамки в библиографии; i18n-структура под казахский. **Дифференциатор:** там, где FAO даёт только концепции, FOLUR добавляет Colab/QGIS/GEE-практику и региональные кейсы.

### 2.3 NASA ARSET + Spatial Thoughts (3 курса) — эталон практики и данных

**ARSET Ag RS** — двуязычность (EN/ES) с параллельной домашкой; навык «поиск и доступ к данным» как отдельная компетенция; практико-ориентированная аудитория; но hands-on минимален, слайды 74–88 МБ (**анти-паттерн для села**). **ARSET ML RS** — производственный end-to-end ML-пайплайн (ingest → loader → train → validate), явный урок **против утечки данных** в split, соавторство с John Deere; но стек **не $0** (AWS+Databricks), US-данные (USDA CDL). **Spatial Thoughts GEE** — **эталон hands-on**: у каждой концепции inline «[Try in Code Editor]», guided-проекты (паводки, осадки, смена покрова), код как разделяемый репозиторий «добавь в свой аккаунт», современные датасеты (Dynamic World, Cloud Score+).

→ **Взято в FOLUR:** «Попробуйте в Colab» после каждой концепции; 3–5 guided-проектов на региональных данных; end-to-end ML с явным split без утечки; навык доступа к данным (GEE Data Catalog, Copernicus); общий репозиторий Colab/GEE; **отказ** от тяжёлых слайдов и платного облака.

### 2.4 ITC / University of Twente (1 курс) — модель «дрон не обязателен»

**UAVs in Precision Agriculture** — главная идея: **готовые UAV-датасеты предоставляются**, вся обработка (ортомозаика → 3D → индексы → агрорешения) выполнима без покупки дрона; три сенсора (RGB/мультиспектр/тепло); измеримые learning outcomes. **Слабости и `[UNVERIFIED]`:** сертификат платный (€50); точный стек ПО и названия 11 юнитов закрыты за логином (не верифицированы); требует ПК и «large data downloads» (риск для села); европейский контекст.

→ **Взято в FOLUR:** модель «дрон не обязателен» — готовые наборы снимков на скачивание (у нас так же с батиметрическим датасетом уровня A); трёхсенсорная структура UAV-темы; замена правил ЕС/NL на нормы РК по БПЛА.

### 2.5 Stepik (3 курса) — эталон русскоязычной дидактики оценивания

**Агроэкология (РГАУ-МСХА)** — полностью русскоязычный, бесплатный, автосертификат; **316 тестовых заданий на 60 уроков** (~5 на урок); паттерн раздела «лекция → практика → "Проверь себя!" → модульный тест»; 961 выданный сертификат (доказанный спрос). **Цифровые технологии в АПК** — 4.92/5 по 547 отзывам; прогрессия «понятия → технологии → применение → **оценка эффективности/ROI**». **ГИС: начальный уровень** — сильная пошаговая практика операций, но проприетарный MapInfo (7 из 11 уроков) и часть видео **без звука** (анти-паттерн доступности). **Общий пробел всех трёх:** нет связки ГИС+ДЗЗ+Python, нет казахстанского контекста, нормативка РФ.

→ **Взято в FOLUR:** ритм «микро-урок → тест сразу»; плотный автопроверяемый банк (наши ~550 вопросов); прозрачные пороги баллов → сертификат; отдельный модуль экономической эффективности (наш П14); русскоязычная агротерминология; **замена** MapInfo на QGIS и достройка отсутствующих RS/GEE/казахстанского контекста.

Практики распределены по 5 категориям (полный список — в навыке `folur-best-practices`; здесь — трассируемость к источникам):

| B. Практика и hands-on | 8 | Spatial Thoughts, NASA ML, ITC, Florida | «Попробуйте в Colab», guided-проекты, «проект на своей земле», «дрон не обязателен», ML без утечек |
| C. Оценивание и сертификация | 5 | FAO ×3, Stepik ×2, Coursera | тест-движок, порог 75%, QR-сертификаты, сценарный экзамен |
| D. Контент и заземление | 7 | Geneva, FAO ×3, Florida, Stepik | региональные кейсы, «границы метода», авторитетные рамки, привязка к нормам РК |
| E. Доступность | 5 | FAO, NASA (анти-паттерн), Geneva | русский+i18n, офлайн-пакет+PDF, лёгкие ассеты, интерактивный хук |

**Незанятая позиция, подтверждённая бенчмарком:** ни один из 14 курсов не сочетает одновременно (1) русский язык, (2) связку ГИС+ДЗЗ+ИИ+Python на $0-стеке, (3) агроэкологию/устойчивое землепользование и (4) региональный контекст Северного Казахстана с реальным датасетом. Платформа FOLUR занимает именно это пересечение — и берёт лучшее из каждого аналога: сертификацию FAO, практику Spatial Thoughts, дидактику оценивания Stepik, структуру Coursera, «дрон не обязателен» ITC.

## 4. Ограничения и честность анализа

- **1 курс не полностью верифицирован** (ITC UAV): стоимость/структура из вторичных источников (DroneLife, gisresources, dronewatch), полный syllabus закрыт за логином — помечено `[UNVERIFIED]`.
- Ряд агрегаторов (Class Central) возвращали HTTP 403 — рейтинги/отзывы по этим курсам брались из доступных страниц провайдера, что отмечено в источниках каждой карточки.
- Метрики популярности (рейтинги, число слушателей) — на дату сбора; со временем меняются.
- **Провенанс:** первичный сбор базы выполнен пятью параллельными workflow 2026-06-23 в рамках подготовки платформы; настоящее приложение — верифицированная выжимка этой базы, оформленная для отчёта ПРООН. Каждая карточка курса сохраняет собственный список источников (5–6 URL) для независимой перепроверки.
