## Агроэкология (Сельскохозяйственная экология)

URL: https://stepik.org/course/84866/promo · Провайдер: Stepik (вузовский МООК, бакалавриат РФ) · Сертификат: Да [UNVERIFIED] · verified: false

**Сильные стороны**
- Полностью русскоязычный, бесплатный, с сертификатом Stepik — нулевая стоимость, совпадает с $0-инвариантом FOLUR
- Высокий рейтинг 4.7/5 (59 отзывов) и большой охват — 4288 учащихся, доказанная востребованность темы агроэкологии на русском
- Очень плотный банк тестов (316 заданий на 60 уроков) — пример удержания русскоязычной аудитории через частую автопроверку знаний
- Сильное системное теоретическое покрытие агроэкологии: устойчивое производство, агроэкомониторинг, нормирование токсикантов, рекультивация загрязнённых земель
- Чёткая привязка к официальным образовательным стандартам (коды специальностей) — модель доверия/легитимности
- Асинхронный самостоятельный формат, легко проходится в своём темпе (12 ч/нед)

**Что заимствовать для FOLUR**
- Плотный автопроверяемый тестовый банк как модель вовлечения (~316 тестов на 60 уроков) — частые короткие квизы после каждого микро-урока; заложить такую же ритмичность автоконтроля в test-engine
- Русскоязычная вузовская терминология и формулировки агроэкологии — готовый словарь/стиль для аудитории СКО
- Привязка к официальным образовательным стандартам/специальностям как сигнал доверия — маппировать модули на признанные компетенции/профессии
- Тематический каркас агроэкологии (устойчивое производство, агроэкомониторинг, рекультивация деградированных земель) как теоретическая основа, обогащаемая ГИС+ДЗЗ+Python и казахстанскими кейсами
- Бесплатный сертификат + асинхронный самотемп-формат — рабочая модель доступа (повторить в GitHub Pages + Colab)
- Краткие микро-уроки с немедленным тестом после каждого — паттерн дробления контента, повышающий завершаемость

**Чего НЕ хватает vs FOLUR**
- НЕТ интеграции ГИС + дистанционного зондирования + Python — ключевой пробел; курс чисто агроэкологический, без геопространственных и вычислительных навыков
- НЕТ контекста Казахстана / Северного Казахстана (СКО/Костанай/Акмола) — материал на стандартах и нормативах РФ
- Ориентация на студентов вузов, а не на практикующих МСБ-агрономов/фермеров — академический язык
- Минимум практики: ~1 ч 09 мин видео, почти нет хэндз-он/проектов, работы с реальными данными или ПО — оценивание сведено к тестам
- Нет работы с открытыми данными, спутниковыми снимками, ноутбуками Colab/Zenodo — нет воспроизводимого цифрового компонента
- Не покрывает FOLUR-специфику: землепользование, деградация земель, восстановление пастбищ, устойчивые цепочки поставок, климат

## Геоинформационные системы: Начальный уровень

URL: https://stepik.org/course/120208/promo · Провайдер: Stepik (индивидуальный курс) · Сертификат: не выдаётся · verified: true

**Сильные стороны**
- Полностью бесплатный, на русском языке, без требований к подготовке — низкий порог входа для аудитории СМБ-практиков
- Сильная практическая ориентация: каждый урок — конкретная операция (оцифровка, регистрация растра, тематические карты, интерполяция изолиний), показанная пошагово на экране
- Покрывает сквозной цикл начинающего ГИС-специалиста: растр → регистрация → векторизация → атрибуты из Excel → тематическая карта → отчёт
- Включает работу с открытым ПО QGIS (совместимо с $0-стеком FOLUR) и получение спутниковых снимков через SASplanet
- Микро-урочный формат (11 коротких уроков) удобен для самостоятельного освоения отдельного навыка

**Что заимствовать для FOLUR**
- Микро-урочная структура «один урок = один конкретный навык» — легко переносится в модульный формат FOLUR
- Сквозной практический маршрут «растр → векторизация → атрибуты из Excel → тематическая карта → отчёт» как канва практического блока по QGIS, но на открытых данных Северного Казахстана
- Русскоязычная подача операций ГИС пошагово на экране — но FOLUR ОБЯЗАТЕЛЬНО добавляет аудио/субтитры и пояснение «зачем» (Bloom: понимание, а не только воспроизведение)
- Импорт табличных данных из Excel в ГИС — реалистичный для агро-СМБ навык (полевые/хозяйственные таблицы → карта)
- Интерполяция изолиний как пример анализа — расширить до агро-применений (картирование почвенных свойств, урожайности) с региональными данными
- ВАЖНО для контраста: курс показывает именно ту нишу, которую FOLUR должен закрыть — заменить проприетарный MapInfo на QGIS+Python и достроить RS (NDVI, GEE/Colab) и казахстанский контекст

**Чего НЕ хватает vs FOLUR**
- Часть видеороликов БЕЗ аудиосопровождения — снижает доступность и педагогическое качество
- Низкий охват и средний рейтинг: 679 слушателей, 3.94/5 по 17 отзывам — не флагманский курс
- Сертификат не выдаётся — нет формального подтверждения для слушателя
- Сильный уклон в проприетарный MapInfo (7 из 11 уроков), не вписывающийся в $0/open-source стек; QGIS покрыт поверхностно (3 урока)
- НЕТ интеграции ГИС + ДЗЗ + Python — спутниковые данные ограничены ручным скачиванием снимка, без индексов (NDVI), временных рядов, GEE
- НЕТ агроэкологического/почвенного/землепользовательского контекста — чистый ГИС-инструментарий без привязки к FOLUR
- НЕТ казахстанского регионального контекста (СКО/Костанай/Акмола) — примеры абстрактные
- [UNVERIFIED] Не подтверждено наличие квизов/тестов и интерактивной проверки знаний

## Цифровые технологии в АПК

URL: https://stepik.org/course/84869/promo · Провайдер: Stepik (аграрный вуз РФ) [UNVERIFIED вуз] · Сертификат: пороги 20/30, но фактически не выдаётся (is_certificate_issued=false) · verified: true

**Сильные стороны**
- Полностью бесплатный, self-paced, на русском языке — низкий барьер входа, совместим с $0-стеком FOLUR
- Высокий рейтинг: ~4.92 из 5 по 547 отзывам — пользователи довольны подачей
- Большой охват: 5840 записавшихся — проверенный спрос на тему цифровизации АПК на русском
- Чёткая модульная структура: 8 разделов, 60 уроков, логичная прогрессия от понятий к оценке эффективности
- Встроенная система оценивания (40 квизов) с прозрачными порогами сертификата (20/30 баллов) — понятная геймификация прогресса
- Раздел 6 «Растениеводство» (13 уроков) — самый объёмный, тематически ближе всего к землепользованию FOLUR
- Включает нормативно-правовой блок и методику оценки экономической эффективности — практикам МСБ важна окупаемость внедрения

**Что заимствовать для FOLUR**
- Русскоязычный квиз-формат с прозрачными порогами баллов (обычный/с отличием) — перенести логику «накопил баллы → сертификат» в FOLUR-платформу
- Модульная прогрессия «понятия → характеристика технологий → применение → эффективность/оценка ROI» — добавить явный модуль по экономической эффективности внедрения (важно для МСБ)
- Выделение крупного отдельного блока по растениеводству (13 уроков) — подтверждает, что прикладной отраслевой раздел должен быть самым объёмным
- Включение нормативно-правового модуля как отдельного раздела — для FOLUR сделать аналог, но на нормах РК (Казахстана), а не РФ
- Высокий рейтинг (4.92/547) подтверждает: «видеолекция + короткий встроенный тест на каждый шаг» работает для русскоязычной агро-аудитории
- Бесплатность + self-paced как базовая модель доступа — совпадает с $0-инвариантом FOLUR

**Чего НЕ хватает vs FOLUR**
- НЕТ интеграции ГИС + ДЗЗ + Python — ключевого технического стержня FOLUR; курс обзорно-теоретический
- НЕТ казахстанского контекста: нормативка привязана к РФ, регион СКО/Костанай/Акмола не покрыт
- Аудитория — студенты-бакалавры аграрных вузов РФ, а НЕ практикующие представители агро-МСБ; пед-дизайн академический
- Практика ограничена автотестами (40 квизов); нет вычислительных ноутбуков, ГИС-проектов, работы с открытыми спутниковыми/полевыми данными
- Не обучает конкретным инструментам (QGIS, GEE, Python-geo) — остаётся на концептуальном уровне
- Тема устойчивого землепользования / агроэкологии / деградации почв (ядро FOLUR) отдельно не выделена
- Сертификаты на момент проверки фактически не выдаются (is_certificate_issued=false), хотя пороги заданы

## Выводы для платформы FOLUR

Главный вывод: **на Stepik существует устойчивый, востребованный русскоязычный рынок** по двум темам FOLUR по отдельности — агроэкология (4288 учащихся, 4.7/5) и цифровизация АПК (5840 учащихся, 4.92/5) — но **ни один курс не закрывает связку, которую строит FOLUR**.

**Языковой разрыв, который заполняет FOLUR.** Все три проанализированных курса русскоязычные и бесплатные — это подтверждает, что русский язык и $0-доступ являются необходимым, но НЕ достаточным условием. Достаточность достигается тем, чего нет ни у кого из них одновременно:

1. **Интеграция ГИС + ДЗЗ (NDVI/спутники) + Python** в едином воспроизводимом стеке. Агроэкологический курс не имеет ГИС вовсе; ГИС-курс ограничен ручными операциями в проприетарном MapInfo без RS и Python; курс по ЦТ в АПК говорит о технологиях лишь концептуально. FOLUR — единственный, кто соединяет геоданные, спутниковую аналитику и вычисления (QGIS + GEE/Colab + Python-geo) на открытом стеке.
2. **Казахстанский / североказахстанский контекст (СКО/Костанай/Акмола).** Все три курса построены на российских стандартах, нормативах и абстрактных примерах. FOLUR заполняет разрыв реальными региональными кейсами, культурами, нормами РК и открытыми данными по конкретным территориям.
3. **Ориентация на практикующих МСБ, а не на студентов вузов.** Бенчмарки академичны (коды специальностей бакалавриата, теоретическая глубина). FOLUR переносит фокус на прикладные навыки фермеров/агро-МСБ с упором на окупаемость внедрения.
4. **Реальный хэндз-он и воспроизводимость.** Оценивание у бенчмарков сведено к тестам/квизам; нет работы с открытыми данными, ноутбуками Colab, публикацией в Zenodo. FOLUR добавляет проектные практикумы на воспроизводимом цифровом стеке.

**Что перенять (проверенные паттерны русскоязычной аудитории):**
- Плотный ритм коротких автопроверяемых квизов после каждого микро-урока (модель Агроэкологии: ~316 тестов / 60 уроков) — заложить в test-engine.
- Прозрачная балльная механика сертификата «накопил баллы → сертификат / с отличием» (пороги 20/30 из курса по ЦТ АПК).
- Микро-урочная структура «один урок = один навык» и сквозной практический маршрут «растр → векторизация → атрибуты → тематическая карта → отчёт» (из ГИС-курса) — но обязательно с аудио/субтитрами и пояснением «зачем».
- Привязка модулей к признанным компетенциям/стандартам как сигнал доверия — но к нормам и профессиям РК.
- Выделение самого объёмного прикладного отраслевого блока (паттерн «Растениеводство — 13 уроков») и отдельного модуля по экономической эффективности внедрения для МСБ.

**Достоверность данных.** Курс `stepik-agroecology` помечен `verified: false` (syllabus рендерится через JS; названия 60 уроков, имена преподавателей и тип сертификата не подтверждены — см. `[UNVERIFIED]`). Курсы `stepik-gis-intro` и `stepik-digital-apk` — `verified: true` (структура подтверждена через Stepik API), но отдельные пункты (наличие квизов в ГИС-курсе, фактическая выдача сертификатов в курсе по ЦТ АПК) также помечены `[UNVERIFIED]`.
