## Sustainable land management and restoration

URL: https://elearning.fao.org/course/view.php?id=454

**Сильные стороны**
- Полностью бесплатный, сертифицируемый и с открытой саморегистрацией — соответствует философии $0-платформы.
- Чёткая логичная 5-урочная арка, повторяющая жизненный цикл проекта SLM: принципы -> планирование -> инструменты внедрения -> стимулы -> мониторинг. Очень переиспользуема как скелет модуля.
- Верифицируемый Open Badges-сертификат с прозрачным порогом 75% и внешней проверкой (Badgecheck.io) — заслуживающая копирования модель сертификации.
- Содержание заземлено на реальные признанные инструменты (WOCAT, ELD) и конкретные кейсы, а не на абстракции.
- Явно мультиаудиторный (политики -> технические специалисты -> фермеры), язык для неспециалистов снижает барьер для МСБ-практиков.
- Привязан к признанной политической рамке (ЦУР 15.3 / нейтральность деградации земель), что даёт внешнюю легитимность.

**Что заимствовать для FOLUR**
- Скопировать 5-урочный жизненный цикл (принципы -> планирование -> инструменты внедрения -> стимулы/экономика -> мониторинг) как каноническую структуру модулей SLM.
- Принять модель сертификации Open Badges: верифицируемый бейдж с прозрачным фиксированным порогом (ФАО использует 75%). Сертификатный движок FOLUR (stdlib) — выровнять порог и добавить метаданные Open Badges + путь внешней верификации (зеркало Badgecheck.io как verify-страница на GitHub Pages).
- Заимствовать идею сценарного / компетентностного финального экзамена (решения по сценариям) вместо чистого выбора ответа — лучше для взрослых МСБ-практиков.
- Воспроизвести мультиаудиторное расслоение (политик / техник / агроном / фермер), но перенастроить под МСБ Северного Казахстана, заменив кейс Замбии на СКО/Костанай/Акмола.
- Переиспользовать рамку WOCAT + ELD: встроить SLM-технологии WOCAT и логику издержки-выгоды ELD, локализованные региональными цифрами, как достоверный слой open-data-инструментов.
- Имитировать позиционирование «global public good / полностью бесплатно, без админ-регистрации» — оно подтверждает инвариант $0 и открытого доступа.
- Привязать модули FOLUR к ЦУР 15.3 / нейтральности деградации земель для международной легитимности русскоязычной программы.
- Там, где ФАО слаба (нет реальной ГИС-лаборатории), дифференцировать FOLUR, добавив практические Colab/QGIS/GEE-ноутбуки, которые ФАО опускает.

## Climate-smart Soil and Land Management

URL: https://elearning.fao.org/course/view.php?id=435

**Сильные стороны**
- Полностью бесплатный, $0-стек — совпадает с инвариантом платформы FOLUR.
- Верифицируемый цифровой бейдж по открытому стандарту Open Badges с метаданными, проверкой в реальном времени и публикацией в LinkedIn/CV — модель сертификации, готовая к копированию.
- Мультиязычность (4 языка: EN/FR/ES/AR) — доказывает, что ФАО строит один курс под несколько языков.
- Чёткий порог сертификации (75%) и компетентностно-сценарный финальный экзамен.
- Короткий, модульный формат (4 урока × 20-50 мин, ~2 ч) — низкий барьер завершения.
- Офлайн-версия для Windows (114.7 MB) — работает без стабильного интернета, важно для сельских районов.
- Встроен в учебное направление (learning path) из ~7 связанных CSA-курсов — модель каталога/трека.
- Прямая привязка к рамке ФАО: добровольные руководящие принципы устойчивого управления почвами (VGSSM).

**Что заимствовать для FOLUR**
- Скопировать модель сертификации Open Badges: верифицируемый бейдж со встроенными метаданными, проверяемый в реальном времени и публикуемый в LinkedIn/CV/email (engine/certificates уже генерирует сертификаты + QR — добавить verify-URL по образцу Badgecheck.io).
- Перенять порог сертификации 75% и компетентностно-сценарный финальный экзамен — для test-engine добавить сценарные/кейсовые вопросы, а не только закрытые тесты.
- Скопировать мультиязычную архитектуру «один курс — несколько языков»: проектировать структуру уроков i18n-готовой, чтобы позже добавить казахский без переработки.
- Перенять модель учебного направления/трека — каталог FOLUR (docs/catalog.md) может группировать 21 модуль в треки с прогрессией, как серия CSA-курсов ФАО.
- Скопировать офлайн-доступность (скачиваемый пакет) для районов с плохим интернетом.
- Перенять короткий модульный формат (уроки 20-50 мин) для вводных модулей, НО усилить практикой там, где FAO слаб.
- ИЗБЕГАТЬ слабого места FAO: где FAO даёт только концепции, FOLUR должен давать реальные региональные кейсы Северного Казахстана, полевые задания и работу с данными/ГИС.
- Перенять привязку к авторитетной рамке (FAO VGSSM): модули по почвам/земле явно мапить на VGSSM.

## Agroecology for Africa

URL: https://elearning.fao.org/course/view.php?id=1256

**Сильные стороны**
- Полностью бесплатный, включая сертифицирующий цифровой бейдж — совпадает с $0-стеком.
- Чёткая компактная 4-урочная структура (~3 ч 45 мин), легко завершаемая и переоформляемая в модульную последовательность.
- Построен на авторитетной рамке ФАО «10 элементов агроэкологии» (одобрена 197 членами ФАО) — достоверный, цитируемый концептуальный костяк.
- Двуязычная подача (EN/FR) демонстрирует рабочую мультиязычную модель одного курса.
- Логичная педагогическая арка: концепция -> экологические принципы -> социальные принципы -> масштабирование.
- Самостоятельный темп, только браузер, с офлайн-пакетом (~68 MB) и PDF-резюме — хорошо для учащихся с плохим интернетом.
- Автоматическая выдача бейджа при пороге 75% — простое прозрачное правило сертификации.
- Активное использование реальных региональных кейсов для заземления абстрактных принципов.

**Что заимствовать для FOLUR**
- Принять модель автоматического цифрового бейджа с фиксированным прозрачным порогом (ФАО использует 75%) — чистое совпадение с zero-cost сертификатным движком; документировать порог открыто, как ФАО.
- Скопировать компактную 4-урочную арку как переиспользуемый шаблон модуля: концепция -> экологические/технические принципы -> социальные/экономические принципы -> масштабирование/внедрение; для FOLUR добавить 5-й урок «инструменты и данные» для покрытия отсутствующего практического слоя.
- Переиспользовать «10 элементов агроэкологии» ФАО как авторитетный цитируемый концептуальный стержень, разделяя экологические и социальные элементы.
- Зеркалировать мультиязычный паттерн одного курса (EN/FR) как модель для русско-первичной + казахско-вторичной подачи.
- Предоставить офлайн-пакет курса (ФАО — ~68 MB) плюс PDF-резюме на модуль — критично для сельских МСБ-учащихся с плохой связью; достижимо через статический экспорт MkDocs.
- Заземлять каждый принцип на реальные кейсы, как ФАО, но заменив африканские кейсы на степные/зерновые кейсы Северного Казахстана (СКО/Костанай/Акмола).
- Сохранить самостоятельный темп и подачу только в браузере — подтверждает достаточность подхода GitHub Pages + статический сайт.
- Где ФАО таргетирует политиков, сознательно перепозиционировать контент FOLUR на МСБ-практиков: оставить урок масштабирования, но добавить конкретные шаги принятия решений на ферме, издержки и разборы инструментов, которые ФАО опускает.

## Sustainable Food Value Chains for Nutrition

URL: https://elearning.fao.org/course/view.php?id=566

**Сильные стороны**
- Полностью $0-стоимость с признанным верифицируемым цифровым бейджем (Open Badge), закрытым экзаменом 75% — достоверная аккредитация по нулевой цене.
- Сжатый завершаемый объём: 4 урока / ~2.5 ч снижает отток у занятых практиков.
- Чёткая педагогическая арка: концепция -> рамка -> impact pathways -> практический дизайн проекта (теория завершается прикладной задачей проектирования).
- Практико-ориентированная аудитория (агенты-консультанты, частный сектор, политики) близко соответствует аудитории МСБ-агро.
- Мультиязычная подача (EN/ES/FR для этого курса; платформа поддерживает 9 языков, включая русский) — проверенная модель локализации.
- Опция офлайн/скачиваемого пакета поддерживает учащихся с плохой связью.
- Опирается на авторитетный институт (ФАО) с опубликованной рамкой SFVC.

**Что заимствовать для FOLUR**
- Принять модель «бейдж, закрытый экзаменом»: выдавать бесплатный верифицируемый кредитив (Open Badge) только после финального теста >=75% — достоверно и $0, вписывается в стек GitHub Pages + cert-engine.
- Скопировать 4-шаговую арку обучения (концепция -> рамка -> impact pathway -> прикладной дизайн проекта) как переиспользуемый шаблон модуля, завершая каждый модуль прикладной задачей, а не пассивным чтением.
- Держать модули короткими и завершаемыми (~2-2.5 ч, ~4 урока) для снижения оттока у занятых МСБ-агропрактиков.
- Сделать рамку цепочки создания стоимости явной и переиспользуемой (FAO SFVC framework + диаграмма impact-pathway) — адаптировать к зерновым/животноводческим/FOLUR-цепочкам Северного Казахстана с региональными кейсами (СКО/Костанай/Акмола).
- Предоставить скачиваемый/офлайн-пакет на модуль для учащихся с плохой связью, но сделать его кроссплатформенным (не только Windows), чтобы превзойти ограничение ФАО.
- Рассматривать мультиязычную подачу как главный дифференциатор: подавать контент FOLUR полностью на русском (кириллица), поскольку ФАО оставляет этот курс только EN/ES/FR — явный пробел локализации, который стоит занять.
- Улучшить слабую оценку ФАО: добавить короткие формирующие квизы на урок (движок test_engine с генерацией вариантов) плюс закрывающий финальный экзамен.

## Выводы для платформы FOLUR

**FAO eLearning Academy — ближайший аналог (peer benchmark) для платформы FOLUR.** Это единственный из изученных провайдеров, который одновременно сочетает: $0-стоимость (включая сертификацию), сертификацию уровня ООН и мультиязычность одного курса. Это напрямую подтверждает ключевые инварианты платформы FOLUR ($0/мес, открытый доступ, без админ-регистрации).

Главные переносимые модели (сквозные через все 4 курса):

1. **Сертификация Open Badges + порог 75%.** ФАО последовательно использует верифицируемый цифровой бейдж (стандарт Open Badges) со встроенными метаданными, проверкой в реальном времени (Badgecheck.io) и публикацией в LinkedIn/CV. Сертификатный движок FOLUR (engine/certificates, stdlib + QR) уже близок — добавить verify-страницу на GitHub Pages и выровнять порог на 75%.
2. **Компактная модульная арка (4-5 уроков, ~2-3.5 ч).** Низкий барьер завершения; завершать модуль прикладной задачей (дизайн проекта / сценарий решения), а не пассивным чтением.
3. **Мультиязычность «один курс — несколько языков».** ФАО доказывает модель; FOLUR делает русский первичным и проектирует i18n-готовую структуру для последующего казахского.
4. **Офлайн-доступность** (скачиваемые пакеты) для сельских районов с плохим интернетом — достижимо статическим экспортом MkDocs (и кроссплатформенно, в отличие от Windows-only пакетов ФАО).
5. **Учебные треки / каталог** (learning paths из связанных курсов) — модель для группировки 21 модуля FOLUR в треки с прогрессией.
6. **Привязка к авторитетным рамкам** (ЦУР 15.3 / LDN, VGSSM, 10 элементов агроэкологии, SFVC) для международной легитимности русскоязычной программы.

**Где FOLUR должен превзойти FAO (общая слабость всех 4 курсов):** отсутствие реальной практики — нет работы с ГИС/данными, полевых заданий, ноутбуков; нет региональной привязки (африканские/глобальные кейсы вместо СКО/Костанай/Акмола); тонкая оценка (единственный финальный экзамен без формирующих квизов); и отсутствие русской локализации. Конкурентное преимущество FOLUR: использовать FAO как концептуальный каркас, затем идти глубже — реальные региональные кейсы Северного Казахстана, запускаемые в Colab open-data ноутбуки (QGIS/GEE), формирующие квизы на урок (движок test_engine с генерацией вариантов и защитой от списывания) и полная русскоязычная подача.

> Примечание о верификации: метки `[UNVERIFIED]` в исходных карточках курсов сохранены — в частности, отсутствие подтверждённой русской локализации этих конкретных курсов, точные пороги/попытки экзаменов на закрытых за логином страницах, и расхождения по длительности. Детали см. в полях `unverified_notes` соответствующих JSON-файлов.
