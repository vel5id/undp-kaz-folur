## UAVs in Precision Agriculture

ITC/Geoversity, ведущий преподаватель F.J. Ellsässer (Assistant Professor). 11 юнитов (~40 часов), self-paced. Сквозной практический pipeline по БПЛА в точном земледелии — без необходимости владеть дроном (данные и ПО предоставляются).

**Сильные стороны**

- Полностью бесплатный контент при $0-стеке: акцент на free and open-source ПО — совпадает с инвариантом FOLUR-платформы.
- Снимает аппаратный барьер: «You don't need your own UAV — we will provide you with all the data and software required» — практика возможна без покупки дрона.
- Сквозной практический pipeline: от планирования миссии → ортомозаика/3D → индексы → агрорешения (биомасса, водный стресс, удобрения).
- Покрывает три типа сенсоров (RGB, мультиспектр, тепло) и реальные агро-кейсы (урожайность, орошение, удобрения).
- Уровень Beginner с минимальными предпосылками — подходит для практиков-аграриев МСБ.
- Self-paced — гибкий темп для занятых фермеров.
- Чёткие, измеримые learning outcomes (evaluate / design / process / estimate).

**Что заимствовать для FOLUR**

- ГЛАВНОЕ: модель «дрон не обязателен» — предоставлять учащимся готовые наборы UAV-снимков (RGB/мультиспектр/тепло) для скачивания, чтобы вся обработка (ортомозаика, индексы, биомасса, водный стресс) выполнялась без владения дроном. Это снимает капитальный барьер для МСБ-аграриев.
- Структура «миссия → карта → индекс → агрорешение» как каркас UAV-модуля: планирование полёта → ортомозаика/3D → вегетационные индексы → конкретное решение (норма удобрений, график орошения).
- Три сенсора в одном модуле (RGB / мультиспектр / тепло) с привязкой каждого к агро-задаче — но заменить на open-data и кейсы СКО/Костанай/Акмола.
- Акцент на free & open-source — но конкретизировать стек под наш инвариант: OpenDroneMap/WebODM + QGIS + Python в Colab, чтобы убрать требование мощного ПК и больших локальных загрузок.
- Чёткие measurable learning outcomes (evaluate/design/process/estimate) — перенести как формулировки целей нашего UAV-урока.
- Практика водного стресса и оптимизации орошения по тепловым снимкам — высокорелевантна для засушливого Северного Казахстана; адаптировать на местные данные.
- Раздел про безопасные/легальные/профессиональные полётные миссии — заменить на нормы РК по эксплуатации БПЛА (а не EU/NL).

> Примечание: точные названия всех 11 юнитов, конкретный стек ПО, глубина оценивания (квизы/проект) и постоянная доступность курса после запуска 2024 года публично не подтверждены [UNVERIFIED]. См. `unverified_notes` в `itc-uav-precision-ag.json`.

## Дополнительно найденные курсы

ITC/Geoversity ведёт обширный каталог бесплатных курсов. Ниже — обнаруженные лиды (полные профили пока не составлены):

- **Exploration of Copernicus and Sentinel Data** — https://www.geoversity.io/courses/exploration-sentinel-data/
  Тема: Earth observation data science / Python / Earth Engine / Sentinel-2. Бесплатный курс ITC/Geoversity по доступу и обработке данных Copernicus, Sentinel-2, Climate Data Store и Google Earth Engine через OpenEO API и Python (Jupyter, IlwisPy), экспорт в QGIS/ILWIS. Прямо поддерживает Python-for-EO, GEE и open-data notebook-стек платформы в модулях по земле/воде/агро.

- **Introduction to ClimateSERV** — https://www.geoversity.io/courses/introduction-to-climateserv/
  Тема: климат / вода / агромониторинг (осадки, влажность почвы, NDVI) + Python API. Бесплатный курс по доступу к осадкам, температуре, влажности почвы, evaporative stress и NDVI для задач продовольственной безопасности и климата — через GUI и Python API ClimateSERVpy. Сильно согласован с водным и агро-мониторинговыми модулями и $0-cost open-data, Python-first подходом проекта.

- **Introduction to Collect Earth Online** — https://www.geoversity.io/courses/introduction-to-collect-earth-online/
  Тема: мониторинг land cover / land use через интерпретацию спутниковых снимков. Бесплатный курс по open-source инструменту: построение проектов интерпретации снимков и эталонных датасетов для ответа на вопросы о трендах land-cover. Хорошо ложится на FOLUR-модули мониторинга земель и требование бесплатного браузерного инструментария на открытых снимках.

- **Earth Observation for Ecosystem Conservation** — https://www.geoversity.io/courses/earth-obs-ecco/
  Тема: дистанционное зондирование / наблюдение Земли для мониторинга экосистем и природных ресурсов. Полностью бесплатный курс ITC/Geoversity по выбору спутниковых снимков, комбинаций каналов и спектральных индексов для мониторинга состояния наземных и морских экосистем. Усиливает основы ДЗЗ и расчёт индексов (напр. NDVI) в модулях мониторинга земель и биоразнообразия.

- **UAVs in Precision Agriculture** — https://www.geoversity.io/courses/uavs-in-precision-agriculture/
  Тема: БПЛА/дроны для агромониторинга (ортомозаики, 3D-облака точек, crop & water stress). Бесплатный 40-часовой курс ITC (опц. платный сертификат): планирование UAV-миссий, обработка снимков в карты и 3D-облака точек, вывод vegetation cover, crop height/biomass/yield и crop water stress. Дрон и опыт не требуются (данные и ПО предоставляются). Прямо поддерживает UAV/drone и агро-мониторинговый контент платформы. *(Полный профиль — `itc-uav-precision-ag.json`.)*

## Выводы для платформы FOLUR

Ключевой педагогический паттерн ITC, который стоит перенести — **«UAV без дрона»**: курс делает полноценную практику по точному земледелию доступной любому, предоставляя готовые наборы UAV-снимков (RGB / мультиспектр / тепло) и ПО для скачивания. Учащийся не покупает дрон и не летает сам — он осваивает весь pipeline обработки: ортомозаика → 3D-облако точек → вегетационные индексы → агрорешение (биомасса, урожайность, норма удобрений, водный стресс, график орошения).

Для FOLUR это снимает главный капитальный барьер для МСБ-аграриев СКО/Костанай/Акмола. Рекомендуемая адаптация:

- Взять каркас «миссия → карта → индекс → агрорешение» и три сенсора (RGB/мультиспектр/тепло), но наполнить open-data и кейсами Северного Казахстана.
- Конкретизировать $0-стек под инвариант платформы: OpenDroneMap/WebODM + QGIS + Python в Colab — это убирает требование мощного ПК на Windows и больших локальных загрузок, на которые опирается оригинал.
- Локализовать на русский (оригинал только на английском) и сделать выдачу сертификата бесплатной (в оригинале €50) — в соответствии с $0-инвариантом.
- Особо проработать водный стресс и оптимизацию орошения по тепловым снимкам — высокорелевантно для засушливого Северного Казахстана.
- Заменить раздел про полётные миссии (безопасность/легальность) на нормы РК по эксплуатации БПЛА вместо EU/NL.
- Перенести стиль measurable learning outcomes (evaluate / design / process / estimate) в формулировки целей UAV-урока.

Сопутствующие курсы ITC (Sentinel/Copernicus, ClimateSERV, Collect Earth Online, EO for Ecosystem Conservation) образуют связный open-data/Python-first набор, согласованный с модулями платформы по земле, воде и агро — их стоит проработать отдельно как источники для notebook-стека.
