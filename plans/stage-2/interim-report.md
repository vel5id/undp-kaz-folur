## 2. Контроль качества (критерии этапа)

- **Внутреннее рецензирование модулей**: двухступенчатое — каждый модуль создан профильным агентом и прошёл независимый аудит по 6-мерной рубрике (учебный дизайн, полнота, доступность, практика/оценка, научная честность с правом вето, региональная привязка). **Вердикт: 21/21 «готов»**, баллы 3.7–4.0; все замечания исправлены на месте (опечатки, рассинхроны счётчиков MCQ, длина предложений, перемешивание позиций правильных ответов).
- **Соответствие FOLUR**: каждый модуль привязан к компонентам FOLUR; факты программы (бюджет $345 млн, «зелёная пшеница», финансовые инструменты) — только веб-верифицированные из `plans/stage-1/03_folur-practices-analysis.md`.
- **Проверка работоспособности платформы**: `validate_content.py` — 154 файла, 0 ошибок (валидность quiz-JSON, обязательные секции, отсутствие реальных координат); `mkdocs build --strict` — код 0; тест-движок проверен в браузере (Playwright): рендеринг, индивидуальность вариантов у трёх тестовых слушателей, подсчёт и порог.
- **Научная честность**: числа о датасете пересчитаны аудиторами из CSV (80 000 строк, глубины 0–16,1 м, среднее 3,40 м — совпадают с текстами); суммы субсидий/нормы РК в модулях принципиально не приводятся (отсылка к adilet.zan.kz/gov.kz); выдуманные числа встречаются только как учебные анти-примеры галлюцинаций ИИ.

## 3. Требование заказчика: ИИ в каждом модуле

Во всех 21 модулях есть `ai-assistant.md` (ИИ-задание с обязательной верификацией результата) и inline-блоки «Попробуйте в Colab»; уровни: pro-code (А1–А6: Claude Code/OpenCode), low-code (П4, П7, П11: Colab+LLM), no-code (остальные П: чат-ассистенты, GIS Copilot, GeoAI-сервисы).

## 4. Правовой режим данных (подтверждено аудитом)

Батиметрия во всех модулях — только уровни A (обезличенный датасет, локальная СК) и B (сетка 100 м); название и координаты водоёма нигде не раскрываются; уровень C упоминается исключительно как «дополнительный материал после юридического подтверждения, возможно исключение».
