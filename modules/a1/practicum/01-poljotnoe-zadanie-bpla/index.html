    Практикум: полётное задание БПЛА на модельный участок и сопоставление с Sentinel-2¶

    ⏱ Трудозатраты: 60–90 мин практики. Модуль А1: Жизненный цикл данных в агросфере (+ БПЛА и IoT). Инструменты: QGIS (свободный), браузер Copernicus (бесплатная регистрация CDSE), Google Colab или калькулятор — только открытый стек. Данные: OpenStreetMap (подложка), Sentinel-2 L2A (Copernicus Data Space Ecosystem) — открытые; дрон не требуется.

    Цель практикума¶

    [Bloom: применять] Самостоятельно спроектировать полётное задание БПЛА на модельный участок пашни в Северном Казахстане — от контура и целевого GSD до схемы маршрутов и оценки времени миссии — и обосновать выбор платформы, сопоставив ожидаемый результат съёмки с реальным снимком Sentinel-2 той же территории.

    Практикум собирает воедино все четыре урока модуля: жизненный цикл и требования к данным (Урок 1), расчёт полётных параметров (Урок 2), решётку выбора платформы (Урок 3), стандарты оформления результата (Урок 4). Итог — прикладной продукт модуля, который предъявляется на аттестации.

    Что нужно подготовить¶

    • [ ] QGIS (актуальная LTR-версия) — свободно, qgis.org; установка ~10 мин.
    • [ ] Аккаунт CDSE (dataspace.copernicus.eu) — бесплатная регистрация для просмотра и скачивания Sentinel-2.
    • [ ] Ноутбук практикума в Colab: <URL будет назначен при создании репозитория ноутбуков> (расчёты можно выполнить и вручную по формулам Урока 2).
    • [ ] Параметры условного учебного сенсора (из Урока 2): пиксель p = 3 мкм, фокусное f = 8 мм, матрица 4000 × 3000.

    Задание¶

    Шаг 1: выбираем модельный участок (10 мин)¶

    Откройте QGIS → создайте новый проект → добавьте подложку OpenStreetMap (панель «Браузер» → XYZ Tiles → OpenStreetMap).

    Установите систему координат проекта: для Костанайской области — UTM 41N (EPSG:32641) или 42N (EPSG:32642) в зависимости от долготы участка; для СКО и Акмолинской — 42N (правило — Урок 4, раздел 1).

    Найдите на подложке массив пашни в одной из трёх областей проекта (СКО / Костанайская / Акмолинская — характерная прямоугольная нарезка полей хорошо видна). Создайте новый слой GeoPackage plot.gpkg (Слой → Создать слой → Новый слой GeoPackage, геометрия — полигон, СК — СК проекта) и оцифруйте контур модельного участка ~100–200 га (одно поле или его часть).

    Ожидаемый результат: файл plot.gpkg с одним полигоном; в свойствах слоя — корректная СК; площадь участка (Вектор → Инструменты геометрии или поле $area) в диапазоне 100–200 га.

    Шаг 2: формулируем задачу съёмки и целевой GSD (10 мин)¶

    Выберите одну из двух легенд (или свою по согласованию с преподавателем):

    • A. Диагностика проблемной зоны: различать объекты от 10 см (колеи, огрехи, пятна сорняков) → минимальный различимый объект 0,10 м.
    • B. Картирование микрорельефа под влагонакопление: различать объекты от 30 см → минимальный различимый объект 0,30 м.

    Рассчитайте целевой GSD по правилу «≥3 пикселя на объект» (Урок 2): GSD = объект / 3. Запишите задачу в одну фразу по шаблону обоснования (Урок 3, раздел 6.1): «различать X от N см на участке S га, однократно/регулярно».

    Ожидаемый результат: записанные значения: минимальный объект, целевой GSD (A: ~3,3 см; B: 10 см), формулировка задачи.

    Шаг 3: рассчитываем параметры миссии (20 мин)¶

    В ноутбуке Colab (или вручную) вычислите для условного сенсора:

    p = 3e-6      # размер пикселя, м
f = 8e-3      # фокусное расстояние, м
W_px, L_px = 4000, 3000   # матрица, пикс
gsd = 0.033   # ваш целевой GSD из шага 2, м

H = gsd * f / p                    # высота полёта, м
W = W_px * gsd                     # захват поперёк маршрута, м
L = L_px * gsd                     # захват вдоль маршрута, м
side, forward = 0.70, 0.80         # перекрытия (равнина, Урок 2)
spacing = W * (1 - side)           # междурядье маршрутов, м
shutter = L * (1 - forward)        # интервал съёмки, м
print(H, W, L, spacing, shutter)

    Затем оцените миссию: измерьте в QGIS ширину и длину участка (инструмент «Измерить линию»), посчитайте число маршрутных линий N = ширина / spacing (округление вверх), суммарную длину Lmiss = N × длина + развороты (~15%) и время T = Lmiss / v при крейсерской скорости v = 8 м/с.

    Ожидаемый результат: таблица параметров миссии — GSD, H, перекрытия, spacing, интервал съёмки, N линий, длина, время. Контроль для легенды A на участке 1000×1500 м: H ≈ 88 м, spacing ≈ 40 м, N ≈ 25–26 линий (если ваш участок другой — числа пропорционально другие).

    Шаг 4: строим схему маршрутов в QGIS (15 мин)¶

    Создайте линейный слой mission.gpkg (GeoPackage, линии, СК проекта). Постройте параллельные линии через рассчитанный spacing: проще всего — оцифровать первую линию вдоль длинной стороны участка, затем Правка → Копировать/Вставить со сдвигом, либо использовать инструмент «Массив смещённых линий» (Processing → «Array of offset (parallel) lines», параметр смещения = spacing). Обрежьте линии по полигону участка с буфером +30 м на развороты (Processing → «Обрезать»).

    Оформите карту: подложка OSM, контур участка, маршруты, стрелка севера, масштабная линейка (Проект → Создать макет) → экспортируйте mission-map.pdf.

    Ожидаемый результат: mission.gpkg с N параллельных линий внутри участка (+буфер) и карта mission-map.pdf.

    Шаг 5: скачиваем фрагмент Sentinel-2 и сопоставляем (15 мин)¶

    В браузере CDSE (dataspace.copernicus.eu → Browser) найдите свежую малооблачную (<20%) сцену Sentinel-2 L2A на ваш участок в вегетационный период. Задокументируйте: дату, идентификатор сцены, облачность (метаданные сцены). Скачайте True Color изображение области участка (кнопка экспорта изображения с геопривязкой) и добавьте GeoTIFF в проект QGIS.

    Приблизьте участок и честно сравните: что видно на 10-метровом пикселе (зоны, границы, крупные неоднородности) и чего не видно (объекты вашей легенды — колеи, пятна от 10–30 см). Сделайте два скриншота одного и того же фрагмента: Sentinel-2 и подложка OSM/план миссии.

    Ожидаемый результат: GeoTIFF фрагмента Sentinel-2 в проекте; записанные дата/ID/облачность сцены; пара сравнительных скриншотов.

    Шаг 6: пишем обоснование выбора платформы (15 мин)¶

    По структуре Урока 3, раздел 6.1 напишите обоснование на 1 страницу (justification.md или PDF): задача → кандидаты (Sentinel-2 / коммерческий спутник / БПЛА) по осям разрешения-периодичности-покрытия → проверка фактов (ваша сцена: дата, облачность; ваш расчёт миссии: время, число линий) → решение (для легенд A/B — БПЛА для детализации + Sentinel-2 для регулярного скрининга) → ограничения и точки пересмотра. Не забудьте пункт правового чека (учёт аппарата, зоны — по актуальным официальным источникам; в учебном задании — как пункт плана, без выполнения).

    Ожидаемый результат: одностраничное обоснование со ссылками на ваши собственные числа из шагов 3 и 5.

    Продукт задания¶

    По итогам практикума у вас должен быть каталог a1-practicum/ (структура — по стандартам Урока 4):

    • [ ] plot.gpkg — контур модельного участка (100–200 га, корректная СК);
    • [ ] mission.gpkg + mission-map.pdf — схема маршрутов и оформленная карта;
    • [ ] таблица параметров миссии (в ноутбуке или parameters.csv);
    • [ ] фрагмент Sentinel-2 (GeoTIFF) + метаданные сцены (дата, ID, облачность);
    • [ ] justification.md — обоснование выбора платформы (1 стр.);
    • [ ] README.md — паспорт мини-датасета: автор, дата, СК (EPSG), источники, инструменты.

    Самопроверка: (1) высота из вашей таблицы, подставленная в формулу GSD, возвращает ваш целевой GSD; (2) N × spacing ≥ ширина участка; (3) все слои проекта — в одной СК, и слой миссии лежит поверх участка без сдвига; (4) в обосновании каждое число прослеживается к шагу 3 или 5; (5) README заполнен по чек-листу Урока 4, раздел 2.

    Применить к своему хозяйству

    Проект на ВАШЕЙ земле. Замените модельный участок на реальное поле вашего хозяйства (или хозяйства-партнёра): оцифруйте его контур по OSM/Sentinel-2, повторите шаги 2–6 под реальную проблему этого поля — и вы получите готовое техническое задание для оператора БПЛА или для собственного полёта. Именно так этот практикум используется в профессиональных модулях П1 и П7. Перед реальным полётом обязателен правовой чек по действующим НПА РК.

    Дополнительные задания (по желанию)¶

    1. Чувствительность бюджета: повторите шаг 3 для GSD 1 см и 5 см; постройте график «GSD → время миссии» и найдите порог, за которым нужен второй аккумулятор (25 мин полезного времени).
    2. Фактическая периодичность: через каталог CDSE посчитайте, сколько малооблачных сцен Sentinel-2 было над вашим участком за июнь–август прошлого сезона (упражнение Урока 3), и добавьте результат в обоснование.
    3. Обработка без дрона: скачайте открытый демонстрационный набор снимков OpenDroneMap (github.com/OpenDroneMap/ODMdata) и соберите из него ортофотоплан в WebODM — полный цикл Урока 1, раздел 4, на реальных аэрофотоснимках.
